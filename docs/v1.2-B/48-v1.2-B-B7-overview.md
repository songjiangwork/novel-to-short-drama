# v1.2-B / B7 — Execution Compilation 总览

状态：**FROZEN**

## 1. 目标与边界

B7 将已经完成 semantic/editorial approval 与 concrete asset approval 的 exact upstream artifacts 编译成现有 v1.1 `ProductionShot` 可消费的 execution specification。

核心定义：

```text
B4 = canonical Shot semantics
B5 = release-specific realization
B6 = concrete asset authority
B7 = execution compilation
v1.1 ProductionShot = compilation target
H3 / ComfyUI = execution backend
```

最重要原则：

```text
B7 compiles decisions.
B7 does not make upstream decisions again.
```

B7 可以做合法 segmentation、timing projection、shot-local asset projection、backend ref/slot 编译、prompt/workflow compilation 与静态 feasibility validation；但不能改 Shot 语义、重做 localization、重新挑 concrete asset、创造新的 generation seam 或通过 backend 限制反向修改 B4/B5/B6。

## 3. Formal inputs

B7 normal compilation 必须消费 exact：

```text
APPROVED + current-lineage EpisodeShotPlan
APPROVED + current-lineage EpisodeReleaseVariant
APPROVED + current-lineage EpisodeResolvedAssetPlan
exact ExecutionProfile revision/hash
```

并验证：

```text
B5 source B4 == exact B4
B6 source B5 == exact B5
approval records target exact id/revision/hash
```

允许显式 `REPLAY_COMPILE` 使用 historically approved immutable lineage；但 replay 不得伪装成 normal current compilation，也默认不移动 normal-current manifest pointer。

## 4. ExecutionProfile

Backend-specific feasibility 与 compilation policy 进入独立 `ExecutionProfile`，而不污染 B4/B5/B6 semantics。

典型内容：

```text
execution_profile_id / revision / hash
backend family / model family
workflow template ref/hash
backend capabilities
reference layout policy
prompt renderer ref/hash
asset staging policy
media execution constraints
compilation policy version
```

ExecutionProfile 可以描述 backend 能接受什么，但不能重新定义 Shot 应该表达什么。

Runtime endpoint、GPU、临时 path、queue id 等不属于 ExecutionProfile semantic identity。

## 5. PlannedShot → ProductionShot

正式 cardinality：

```text
PlannedShot → 1..N ProductionShots
```

每个 ProductionShot：

- 属于 exactly one PlannedShot；
- 对应一个连续 semantic time interval；
- 同一 PlannedShot 的全部 ProductionShots 完整覆盖且无 semantic gap/overlap；
- 多个 PlannedShots 不得 silent merge 成一个 ProductionShot。

1→N 只表示 generation segmentation，不表示 backend 内部多 pass、compositing pass 或 workflow task。

所有 internal seam authority 必须来自 B4.5 `GenerationSegmentationContract`；backend limit 只能形成 partition constraint，不能创造 seam。

## 6. ProductionShot identity

Formal logical identity：

```text
ProductionShotIdentity
=
episode
+
ReleaseVariantIdentity
+
planned_shot_id
+
segment_identity
+
ExecutionProfile ID
```

`segment_identity` 来自 boundary pair，而不是 `SEG01` ordinal。

因此：

- ReleaseVariantIdentity 改变 → new identity；
- ExecutionProfile ID 改变 → new identity；
- segment topology/boundary pair 改变 → new identity；
- prompt/asset/profile revision 等 execution content 改变但 identity dimensions 不变 → normally new ProductionShot revision。

`GenerationAttempt` 与 ProductionShot identity/revision严格分离。

## 7. Timing / dialogue / audio projection

B7.3 保持：

```text
B4 canonical timing
≠ B5 release timing
≠ ProductionShot-local timing
```

B7 只做 projection，不重写 dialogue、subtitle、reveal、audio event 或 release hold。

跨 segment event 保留 source semantic identity；允许时间区间 projection，但不得按时长比例猜 linguistic split。

普通外挂 subtitle 不进入 H3 visual prompt。

同时严格区分：

```text
SemanticWindow
≠ RenderEnvelope
≠ ContextEnvelope
```

Backend padding/trim/pre-roll/post-roll/continuation overlap 不得反写 B4/B5 timing authority。

## 8. Per-ProductionShot asset projection

B7.4 只能从 exact APPROVED `EpisodeResolvedAssetPlan` 与其 `EffectiveAssetBindingIndex` 中投影资产：

```text
approved effective asset universe
↓
minimum sufficient approved shot-local subset
```

B7 不得绕回 AssetCatalog、重新看图/听音频、重新做 compatibility reasoning 或替换 concrete asset。

继续保持：

```text
AssetKind
≠ ExecutionAssetRole
≠ BackendReferenceRole
≠ Picture N
```

`VOICE_REFERENCE` 与 `PREEXISTING_UTTERANCE_AUDIO` 严格分离；generated utterance audio、previous-segment frame 等属于 runtime-derived artifacts，不冒充 B6 source assets。

## 9. Reference layout / Picture N

B7.5 是 backend reference ordering / channel / logical slot / `Picture N` 的唯一 authority。

数据流：

```text
AssetRecord
↓
ExecutionAssetRole
↓
BackendReferenceRole
↓
BackendReferenceChannel
↓
logical slot / ordinal
↓
Picture N / rendered token
```

Prompt renderer、workflow compiler、staging、request builder 都必须消费同一个 authoritative `BackendReferenceBinding` graph，不得独立排序。

`Picture N` 是 ProductionShot-local rendered ordinal，不是 asset identity。

## 10. Prompt / workflow compilation

B7.6 正式区分：

```text
ExecutionSemanticSpec
↓
BackendPromptSpec
↓
RenderedBackendPrompt
```

`ExecutionSemanticSpec` 才是 per-ProductionShot execution semantic authority；rendered prompt 不是 semantic source-of-truth。

Normal prompt rendering deterministic/versioned，不依赖 Qwen 自由改写。

B7.6 同时编译：

- backend semantic coverage；
- render/context envelope；
- workflow parameter bindings；
- symbolic runtime-derived dependencies；
- AttemptVariableContract。

Compile-time workflow binding 与 attempt-time materialized ComfyUI JSON 分离。实际 seed、staged paths、endpoint、queue/output locator 等属于 GenerationAttempt。

## 12. Assembly

B7.8 只消费 exact B7.7 PASS / PASS_WITH_DIAGNOSTICS bundle，deterministic materialize：

```text
existing v1.1 ProductionShot × N
+
EpisodeExecutionManifest
```

B7.8 不重新 render prompt、不重新排序 refs、不重新算 segment/timing/assets/workflow。

ProductionShot 保存 execution-critical immutable payload，并 pin B4/B5/B6/B7 exact provenance；attempt-specific runtime values不固化其中。

## 13. EpisodeExecutionManifest

Manifest identity：

```text
episode
+
ReleaseVariantIdentity
+
ExecutionProfile ID
```

Manifest 保存：

- exact ordered ProductionShot refs；
- release/editorial sequence；
- runtime dependency DAG；
- exact source lineage / validated bundle。

Release sequence 与 execution dependency graph严格分离。Manifest 是“应该执行什么”的 authority，不是“实际生成了什么”的日志。

同一 manifest identity 最多一个 normal-current revision；历史 revisions immutable。Current manifest pointer 只能在完整 assembly 成功后 atomic swap。

## 14. Retry / QC boundary

```text
ProductionShot revision
↓
GenerationAttempt 1..N
↓
GeneratedArtifact
↓
QC
```

只在 `AttemptVariableContract` 内变化才属于 retry，例如 seed、runtime locator、resolved runtime-derived input。

如果需要改：

```text
prompt
asset subset
Picture ordering
workflow binding
segment boundary
timing semantics
dependency policy
```

则必须 recompile，而不是继续同一 ProductionShot revision 的 retry。

## 15. v1.1 compatibility

