# B7.7 — Execution Compilation Validation

状态：**FROZEN**

## 1. 职责

B7.7 是 read-only integrated compiler auditor。

它验证从 exact B4/B5/B6 approved lineage 到 B7.6 backend execution spec 的整条编译链是否：

```text
lineage correct
semantically faithful
internally consistent
backend-feasible
reference-consistent
reproducible
```

但绝不在 validation 阶段修改任何 artifact。

核心：

```text
validation
≠ repair
≠ recompilation
≠ semantic revision
≠ human editing
```

## 2. 正式输入

B7.7 必须消费 exact：

```text
ExecutionCompilationContext
EpisodeProductionShotSegmentationPlan
EpisodeProductionShotTimingProjectionPlan
EpisodeProductionShotAssetProjectionPlan
EpisodeBackendReferenceLayoutPlan
EpisodeBackendExecutionSpecificationPlan
```

并解析其中 pin 的 exact：

```text
APPROVED EpisodeShotPlan
APPROVED EpisodeReleaseVariant
APPROVED EpisodeResolvedAssetPlan
ExecutionProfile
SegmentationPolicy
ReferenceLayoutPolicy
PromptRenderer
WorkflowTemplate
WorkflowParameterContract
DurationRealizationPolicy
other execution-affecting compiler policies
```

禁止 `latest/current/default` implicit resolution参与 validation。

## 3. 正式输出

输出：

```text
ExecutionCompilationValidationReport
```

概念包含：

```text
execution_compilation_context_ref
validated_artifact_refs
validated_policy_refs
episode_checks
production_shot_checks[]
diagnostics[]
result
validated_execution_compilation_bundle_hash
validator_version
content_hash
```

## 4. Result

正式结果：

```text
FAIL
PASS_WITH_DIAGNOSTICS
PASS
```

`PASS_WITH_DIAGNOSTICS` 只用于 non-blocking、non-semantic-drift、non-feasibility-breaking diagnostics，例如 recommended ref count exceeded but hard limit satisfied、保守保留 scope不够细的 approved asset、较大合法 render bucket。

以下不能降级成 diagnostic：

```text
required semantic unmapped
asset hash mismatch
Picture mapping uncertain
voice binding uncertain
backend hard constraint violated
```

这些必须 FAIL。

## 5. Read-only firewall

B7.7 MUST NOT：

```text
move seam
change timing
drop/add asset
reorder refs
renumber Picture N
rewrite prompt
patch workflow
change ExecutionProfile
fill missing parameter
select fallback backend
```

Finding只输出：

```text
what failed
where
owner stage
repair route
```

## 6. V1 — Upstream lineage / approval integrity

验证：

```text
B5 source B4 == context exact B4
B6 source B5 == context exact B5
approval records target exact id/revision/hash
```

`NORMAL_COMPILE` 必须是 exact current-lineage。

`REPLAY_COMPILE` 可使用 historically approved immutable lineage，但必须整条 internally consistent，不允许 current B4 + old B5 + new B6混装。

Replay不得伪装 normal eligibility。

## 7. V2 — Compiler artifact chain integrity

逐层检查：

```text
B7.3 source segmentation hash == exact B7.2
B7.4 source refs == exact current B7.2/B7.3
B7.5 source asset projection hash == exact B7.4
B7.6 refs == exact B7.2–B7.5
```

禁止 mixed compiler generations。

所有 ExecutionProfile / policies / renderer / template exact revision/hash必须与实际 compilation声明一致。

## 8. V3 — ProductionShot topology / identity

每个 PlannedShot必须：

```text
map to 1..N ProductionShots
```

每个 ProductionShot exactly one PlannedShot。

Segments必须按 release timeline有序、连续、完整、无 semantic overlap/gap：

```text
union(segment semantic windows)
= exact PlannedShot release realization window
```

Formal `ProductionShotIdentity` 必须符合 B7.2 frozen model：

```text
episode
+ ReleaseVariantIdentity
+ planned_shot
+ boundary-pair segment identity
+ ExecutionProfile ID
```

不得用 `SEG01` ordinal作为 identity authority。

## 9. V4 — Segmentation / boundary authority

每一个 internal seam必须 resolve到 B4.5 authorized boundary，并满足 B5 release-specific seam constraints。

Backend duration/reference pressure不得造成 invented timestamp seam。

若 boundary无法追溯：

```text
FAIL
```

## 10. V5 — Timing projection integrity

验证 source release timing → projected release timing → local timing 的数学一致性。

Local conversion不得通过 rounding/normalization移动 event。

跨 segment DialogueEvent / SubtitleCue / AudioEvent / ReleaseHold必须保持 source semantic identity。

## 11. Cross-segment dialogue validation

若 utterance跨 seam，必须至少存在正式 realization path：

```text
timed linguistic subspans
or continuous audio realization
or ExecutionProfile-supported continuation
```

否则：

```text
CROSS_SEGMENT_UTTERANCE_UNREALIZED
```

Prompt看起来“可能能说完”不能作为 pass evidence。

## 12. Subtitle / point-event / bridge checks

必须确认：

- Subtitle projection不提前 reveal；
- 普通 subtitle没有泄漏成 visual-generation semantics；
- exact seam point event有 exactly one execution owner；
- audio bridge source/target/timing/continuity完整；
- audio bridge与 backend frame overlap provenance不混淆。

## 13. V6 — Asset authority

每个 B7.4 projected source asset必须存在于 exact approved `EpisodeResolvedAssetPlan`，并 pin exact：

```text
asset_id
revision
content_hash
```

禁止 catalog-only、filesystem-discovered、runtime substitute或 unapproved similar asset进入 source projection。

## 14. Effective binding / requirement coverage

每个 active B6 requirement必须通过 B6.6 `EffectiveAssetBindingIndex`解析。

`REQUIRED` 与 active `CONDITIONAL` 不得 unresolved/drop。

Combination policy必须完整：

```text
SINGLE_SUFFICIENT
COMPLEMENTARY_ALLOWED
COMPLEMENTARY_REQUIRED
ALTERNATIVE_ONE_OF
```

尤其 `COMPLEMENTARY_REQUIRED` 不得在 shot-local projection少 member；`ALTERNATIVE_ONE_OF` 到 B7必须已经 resolved。

## 15. Minimum sufficient / continuity validation

B7.7不要求无条件最小 count，而检查：

```text
no provably redundant ref
and
no required/continuity ref removed
```

Scope不够细而保守 retain可成为 diagnostic。

同一 PlannedShot split segments如果 requirements不变却无理由在 face_100 / face_75之间抖动，可视为 continuity/projection failure。

## 16. Voice / runtime-derived provenance

必须保持：

```text
VOICE_REFERENCE
≠ PREEXISTING_UTTERANCE_AUDIO
≠ runtime-generated utterance audio
```

Previous frames、generated waveform、derived mask等 runtime-derived inputs不得出现在 B7.4 B6-authorized source asset list，只能存在于 B7.6 dependency declarations。

## 17. V7 — Reference layout integrity

对每个 binding验证完整链：

```text
asset_ref
→ ExecutionAssetRole
→ BackendReferenceRole
→ channel
→ logical slot
→ ordinal/token
```

B7.5不得丢失 required projected source refs，也不得添加未授权 source refs。

## 18. Picture N uniqueness

每个 ProductionShot visual channel必须：

```text
unique ordinal
unique rendered token
one authoritative binding per ordinal
```

禁止：

```text
two assets → Picture 2
Picture token without binding
```

## 19. V8 — Prompt / reference / workflow parity

Validation不得只比字符串名，而应通过 `reference_binding_id` 验证：

```text
BackendPromptSpec symbolic reference
↓
same B7.5 binding
↓
workflow logical slot
↓
staging source bytes
```

如果 prompt把 Picture 2当 classroom，而 workflow slot 2实际绑定 Linsey：

```text
FAIL
```

即使两张图片都已传入。

这是防止 prompt/workflow/staging三方 drift 的 hard invariant。

## 20. Capacity validation

Integrated re-check：

```text
channel-local capacity
global shared capacity
role constraints
required slot availability
duplicate policy
```

超 hard limit必须 FAIL。

如果 B7.5曾通过 constraint feedback尝试 alternate partitions，最终 report不得仍有 pending repartition/cycle；legal partition search必须终止。

## 21. V9 — Backend semantic coverage

B7.6 `BackendSemanticCoverageMap` 必须为每个 required ExecutionSemanticSpec item提供真实、可解析 realization path。

例如 coverage声明：

```text
location identity → REFERENCE_BINDING RB_CLASSROOM
```

则 `RB_CLASSROOM` 必须真实存在。

声明：

```text
9:16 framing → WORKFLOW_PARAMETER
```

则 exact workflow binding必须存在。

External subtitles等可以通过 `EXTERNAL_RELEASE_OPERATION`合法覆盖。

## 22. Unauthorized semantic injection

B7.7 还要反向检查 backend spec/prompt 是否加入 upstream未授权 creative facts，例如：

```text
new character
new costume
sunset/rain
new camera orbit
new action/reveal
```

Backend-required syntax没问题；新的故事/editorial decision必须：

```text
UNAUTHORIZED_BACKEND_SEMANTIC_INJECTION
```

## 23. Preservation coverage

不仅 positive semantics必须覆盖，以下 preservation constraints也必须有 realization：

```text
character identity
location identity
orientation
co-visibility
no-extra-character
continuity state
```

不能只证明“生成了什么”，还要证明“关键的不能漂移什么”已进入 backend contract。

## 24. V10 — Deterministic prompt/workflow compilation

Validator可独立重跑 canonical deterministic render check：

```text
BackendPromptSpec + B7.5 layout + PromptRenderer revision
→ exact rendered prompt hash
```

不同则：

```text
NONDETERMINISTIC_PROMPT_RENDER
```

WorkflowTemplate + ParameterContract + binding spec同样必须 deterministic。

## 25. V11 — Workflow template integrity

实际 template bytes必须匹配 pinned hash。

如果 path同名但 bytes变了：FAIL。

检查 template不得残留 dynamic production state：

```text
old asset refs
old prompt
old production duration
old dialogue
old production-specific dimensions
old actual seed
```

Declared ExecutionProfile constants允许；undeclared execution-affecting defaults失败。

## 26. V12 — Render/context realization

验证：

```text
SemanticWindow ⊆ RenderEnvelope
```

Render duration必须属于 exact profile合法 range/bucket。

Extra render tail必须有显式 non-semantic trim/hold/context treatment。

Pixel dimensions必须来自 profile合法 realization且不违反 B5 aspect/framing contract。

ContextEnvelope不得被误计为 semantic content。

## 27. V13 — Runtime dependency graph

所有 `RuntimeDerivedInputRequirement` producer必须存在并合法。

Dependency graph baseline要求 acyclic：

```text
PS-A depends on PS-B
PS-B depends on PS-A
→ RUNTIME_DEPENDENCY_CYCLE
```

Predecessor continuation不得随意指向 unrelated scene output，除非 profile/semantics明确授权。

Compile artifacts不得提前 pin future queue id / attempt filename / actual derived frame hash。

## 28. V14 — AttemptVariable boundary

允许 attempt-variable：

```text
seed
runtime endpoint
staged locator
resolved runtime-derived bytes/hash
queue metadata
output locator
```

禁止 attempt-variable：

```text
prompt semantics
asset selection
reference order/Picture mapping
segment boundaries
workflow template
timing semantics
```

否则 retry可以绕过 ProductionShot revision discipline。

## 29. V15 — Runtime-vs-compile boundary

Compiler artifacts不得固化当前 runtime state：

```text
localhost URL
current queue
GPU UUID
PID
temporary directory
actual output filename
actual random seed
```

除非以 symbolic runtime variable declaration存在。

ComfyUI当前离线、GPU忙不是 B7.7 compiler FAIL；这些属于 execution preflight/runtime condition。

## 30. Static feasibility ≠ output quality

B7.7 PASS表示：

```text
the approved semantics have been coherently compiled
into a valid backend execution specification
```

不表示生成视频一定通过 QC。

B7.7不调用 H3/ComfyUI，也不通过“实际跑一下”定义 validation。

## 31. Architecture leakage

Validator检查 stage boundary：

- B4/B5/B6 不应出现 Picture N / ComfyUI node / workflow slot；
- B7.2/B7.3/B7.4 不应出现 concrete ComfyUI node mapping；
- B7.6 不应出现新的 AssetCandidate / compatibility score / arbitrary catalog search；
- B7 不应创造新的 editorial Shot boundary。

## 32. Diagnostics / repair route

每个 finding至少包含：

```text
finding_code
severity
artifact_ref
production_shot_identity
description
owner_stage
repair_route
related_refs
```

Validator描述 expected vs actual，但不得直接写修复后的值或 mutate artifact。

## 33. validated bundle hash

成功 `PASS` / `PASS_WITH_DIAGNOSTICS` 后生成：

```text
validated_execution_compilation_bundle_hash
```

至少覆盖：

```text
ExecutionCompilationContext hash
B7.2–B7.6 hashes
ExecutionProfile hash
execution-affecting policy/template/renderer hashes
validator schema/version
```

ValidationReport必须明确 pin validator version。

## 34. Validation invalidation

Validation后任何 covered artifact改变，例如 prompt一个字、Picture order、asset subset、workflow template、timing projection，都使旧 validated bundle失效。

必须重新 B7.7。

## 35. B7.8 downstream contract

B7.8不得从 loose B7.2–B7.6 files assembly。

只能消费：

```text
ExecutionCompilationValidationReport
result = PASS / PASS_WITH_DIAGNOSTICS
+
exact validated_execution_compilation_bundle_hash
```

## 36. Human / Qwen boundary

B7.7无 formal human approval gate。

Formal result由 deterministic Python validator rules决定。

Qwen可以读取 report做 root-cause explanation / repair recommendation，但不能把 FAIL主观改成 PASS。

## 37. 冻结原则

1. B7.7是 read-only integrated compiler auditor。
2. 不 repair/mutate任何 artifact。
3. 验证 exact B4→B5→B6→B7 lineage、approval、hashes。
4. NORMAL与REPLAY eligibility严格分离。
5. Mixed compiler generations禁止。
6. Execution-affecting profiles/policies/templates exact pin。
7. Segment topology完整且 seams全部可追 B4.5 authority。
8. Timing projection可数学追溯并保持 source event identity。
9. Cross-segment dialogue必须有 formal realization path。
10. Subtitle reveal与 point-event ownership严格验证。
11. B7.4 source assets必须来自 exact approved B6 plan。
12. Active requirements / combination policies / continuity不得被削弱。
13. Runtime-derived artifacts不得冒充 B6 assets。
14. Picture N / slot mapping必须 unique/auditable。
15. Prompt/workflow/staging必须共享同一 reference binding graph。
16. Prompt-reference-workflow ordering mismatch是 hard FAIL。
17. 每个 required semantic必须有真实 backend realization path。
18. Backend不得 inject未授权 creative semantics。
19. Prompt/workflow compilation必须 deterministic reproducible。
20. Template hash、parameter binding、hidden defaults严格检查。
21. Semantic / render / context envelopes严格分离。
22. Runtime dependency graph必须可解析且 acyclic。
23. AttemptVariableContract不得允许 spec级字段变化。
24. Runtime availability不是 compiler validation。
25. PASS不替代 downstream QC。
26. 成功生成 exact validated_execution_compilation_bundle_hash。
27. Covered artifact变化使旧 validation失效。
28. B7.8只能从 exact validated bundle assembly。
29. B7.7无 human gate，normal path不依赖 Qwen。
