# B4.5 — Shot Duration + Generation Segmentation

状态：**FROZEN**

## 1. 职责

B4.5 负责：

```text
Editorial Shot Timing
+
Generation Segmentation Contract
```

它不实例化 concrete generation segments，也不创建 v1.1 ProductionShot。

正式输出：

```text
EpisodeShotTimingPlan
```

## 2. 为什么 segmentation 不能现在 materialize

B4 此时仍未解析：

- final release language
- exact spoken duration
- aspect-ratio realization
- concrete assets
- backend ExecutionProfile

因此 canonical Shot Planning 只能规定一个 PlannedShot 是否允许 split、哪里安全、哪里禁止以及 seam continuity 必须保持什么；最终 segment count 由 downstream execution compilation 决定。

## 3. ShotTimingSpecification

每个 PlannedShot exact 对应一个 `ShotTimingSpecification`，回答：

- semantic start/end moments
- must-hold performance/action/reveal
- estimated target duration
- optional acceptable range
- timing flexibility

Shot timing 由 dialogue、action、reaction、pause、readability、attention progression 与 continuity 驱动，而非 backend clip length。

## 4. ShotTimingAnchor

允许 lightweight `ShotTimingAnchor` 引用：

- ScreenplayElement
- StagingDirective
- PerformanceRequirement
- PCR
- action/dialogue semantic phase

关系可使用：

```text
BEFORE
AT_START
DURING
AT_COMPLETION
AFTER
```

Canonical timing 优先绑定 semantic event，而不是绝对秒数或特定语言字符/词数。

## 5. Duration estimates

可保存 `target duration`，并在真正有语义依据时保存 optional min/max 或 acceptable range。

不得为了 schema 完整制造虚假的精度，也不使用“所有 CLOSE 至少 N 秒”等 universal rules。

支持：

```text
must_hold_through
must_not_cut_during
```

以保护关键 reaction、reveal、physical interaction 与 continuous performance。

## 6. Editorial Cut vs Generation Boundary

```text
Editorial Cut
= 观众能感知到的镜头切换
= B4.2 authority

Generation Boundary
= backend execution 对同一 continuous PlannedShot 的技术 seam
= downstream concern
```

Generation Boundary 不创建新的 PlannedShot。

## 7. GenerationSegmentationContract

每个 PlannedShot 可定义：

```text
SINGLE_PREFERRED
SPLIT_ALLOWED
SPLIT_DISCOURAGED
SPLIT_FORBIDDEN
```

它回答是否可 split，不回答最终 split 几段、每段几秒或用什么 backend。

`SPLIT_FORBIDDEN` 只应用于核心意义依赖真正连续 realization 的少数 Shot，不作为默认偏好。

## 8. Safe / forbidden seam

可标记 `SegmentationBoundaryCandidate`，例如 action completion、stable pose、dialogue beat boundary、environmental hold。

Candidate 不是 actual split。

可同时标记 forbidden regions，例如：

- object handoff
- critical microreaction
- fast continuous movement
- camera arc midpoint
- uninterrupted performance beat

## 9. Seam continuity

Generation split 后必须仍被观众理解为同一个 continuous PlannedShot。Seam contract 至少保护：

- same PlannedShot identity
- same camera semantic state/progression
- ProductionContinuity
- action/performance phase continuity
- prop/environment state
- no unauthorized reposition/reset
- no perceptible editorial transition

如果 seam 最终必须产生 visible cut，则必须返回 B4.2 创建新的 PlannedShots。

## 10. Localization / Release Variant

Release Variant 可在 B4.5 timing flexibility 内根据 spoken language、subtitle/release pacing 等调整 exact duration，而不要求 canonical B4 revision。

若所需 duration 超出 canonical timing contract，则 route 回 B4.5；若必须增加真实 editorial Shot，则返回 B4.2。

B4.5 不要求提前生成 TTS/WAV。

## 11. Timing reconciliation

B4.5 应 reconciliation：

- Shot semantic duration
- ProductionUnit duration budget
- episode duration target/range

并行动作/对白不能简单算术相加；Python 处理 ranges/arithmetic，Qwen 辅助 semantic overlap 与 pacing reasoning。

Shot density、average shot duration 等可以作为 diagnostics，不是 quality gate。

## 12. Backend boundary

具体 H3/ComfyUI clip limit、GPU/runtime 能力不进入 canonical `EpisodeShotTimingPlan`。这些属于 downstream `ExecutionProfile`。

一个 PlannedShot 最终可 compile 为 1..N ProductionShots；实际 N 不由 B4.5 决定。

## 13. Revision authority

B4.5 有独立 id/revision/hash。以下通常只产生 B4.5 revision：

- target/range change
- semantic timing anchor refinement
- must-hold/no-cut change
- segmentation policy
- safe/forbidden seam change
- seam continuity requirement

若需要改 transition semantics 回 B4.4；camera semantics 回 B4.3；真实 editorial split/merge 回 B4.2。

## 14. 冻结原则

1. B4.5 输出 versioned `EpisodeShotTimingPlan`。
2. Shot timing semantic-first，backend segmentation later。
3. Canonical timing 不绑定单一语言或 frame-accurate timeline。
4. `GenerationSegmentationContract` 不实例化 segments。
5. Editorial Cut 与 Generation Boundary 严格分离。
6. Seam 必须保持 single PlannedShot continuity。
7. Actual ProductionShot segmentation 留 downstream execution compilation。
8. Backend-specific clip limits不得污染 canonical Shot Plan。
9. B4.5 不增加 formal approval gate。
