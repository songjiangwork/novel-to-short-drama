## 3. Event production decision

Freeze：

```text
event-semantic-packing-v1

max_pairs_per_block      = 12
max_candidates_per_block = 24
```

Equivalent audited candidate：

```text
P2
```

Rationale：

1. P1 → P2 reduces provider block count from 491 to 246, almost exactly 50%, while keeping maximum rendered prompt at 29,600 bytes.
2. P2 keeps the maximum expected response decision count at 12.
3. P3 halves calls again (246 → 123) but doubles the response decision count to 24.
4. P3 increases median rendered prompt from 23,229 to 43,691 bytes and maximum from 29,600 to 55,706 bytes.
5. P3 maximum evidence items per block reaches 96, versus 48 for P2.
6. The shared semantic profile has `max_output_tokens = 4096`; A5 semantic output includes per-pair refs, decision, Chinese reason, and evidence selectors. A 24-decision response materially reduces output headroom.
7. A5 follows precision/reliability-first semantics. The extra 123 provider calls saved by P3 do not justify the larger prompt/output surface and larger block-atomic retry unit.

Therefore:

```text
P2 is the frozen Event v1 balance:
  meaningful call reduction
  bounded request size
  bounded 12-decision response
  lower block-atomic retry exposure
```

## 5. Relationship production decision

Freeze：

```text
relationship-semantic-packing-v1

max_pairs_per_block      = 12
max_candidates_per_block = 24
```

Equivalent audited candidate：

```text
P2
```

Rationale：

1. P1 → P2 reduces provider calls from 72 to 36 while keeping max rendered prompt at 21,337 bytes.
2. P2 limits each structured response to at most 12 relationship decisions.
3. P3 saves only 18 further calls across the complete Alice relationship stream.
4. That small absolute saving doubles the per-block decision count from 12 to 24 and raises max rendered prompt from 21,337 to 39,254 bytes.
5. The 4096 output-token budget is shared with reason_zh and evidence selectors; 24-decision blocks unnecessarily reduce output headroom.
6. Block failures/retries are atomic. With only 36 P2 blocks, the operational benefit of P3 is small while the retry/failure unit doubles.
7. Relationship identity is semantically sensitive to endpoint direction, relationship type, and state evidence. v1 should optimize semantic reliability rather than minimize an already-small call count.

Therefore:

```text
P2 is the frozen Relationship v1 balance.
```

## 6. Frozen production policies

The two domains were reviewed independently and happen to converge on the same behavioral limits:

```text

  max_pairs_per_block      = 12
  max_candidates_per_block = 24

relationship-semantic-packing-v1:
  max_pairs_per_block      = 12
  max_candidates_per_block = 24
```

This does **not** make them one shared semantic policy identity.

They remain distinct policy names / domain authorities:

```text
event-semantic-packing-v1
relationship-semantic-packing-v1
```

A future behavior change may version one domain independently of the other.
