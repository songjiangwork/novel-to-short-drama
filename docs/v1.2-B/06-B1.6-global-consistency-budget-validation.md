# v1.2-B1.6 — Global Consistency / Budget Validation（冻结）

## 职责

B1.6 是对完整 B1.1–B1.5 semantic artifact set 的只读 integrated audit。

核心边界：

```text
B1.6 = verify + diagnose + route

B1.6 != repair
```

它不能创造故事、不能重新 partition、不能静默修改任何 upstream B1 artifact。

---

## 输入

B1.6 消费当前完整 semantic set：

```text
ResolvedAdaptationTarget
AdaptationStrategy
SourceDispositions
AdaptationMappings
AdaptedCharacters
AdaptedContinuity
AdaptedStorySkeleton
PresentationStructure
EpisodePlan
StoryBible / Canonical revision refs
```

正常 validation 不重新读取小说全文；只有某个 semantic finding 需要 source verification 时，才沿 stable IDs / provenance 定向回溯 evidence。

---

## Validation Input Set

每份 validation report 必须绑定精确输入版本：

```text
artifact IDs
revisions
content hashes / equivalent immutable identity
```

目的：明确“这份 validation 到底验证了哪一版 AdaptationPlan constituents”。

如果 EpisodePlan 基于旧 Skeleton revision，或文件内容在 validation 后发生变化，必须 fail closed / require revalidation。

这只是 B1 bundle 内 version compatibility，不负责未来 project-wide stale propagation。

---

## Audit Dimensions

### 1. Identity / Reference Integrity

Python 检查：

- canonical IDs 存在
- AdaptedCharacter / AdaptedBeat IDs 存在
- PresentationEntry / Episode refs 存在
- mapping endpoints 存在
- no duplicate authoritative IDs
- revision set compatible

### 2. Adaptation Target Realization

检查最终 plan 是否满足 B1.1：

- fixed episode count
- hard duration constraints
- required elements
- forbidden elements
- focus / fidelity target 中可确定的约束

### 3. Adaptation Strategy Realization

检查 B1.2 宣布的 thesis / plot / character / relationship / ending strategy 是否被 B1.3–B1.5 实际实现。

Python 提供结构化 evidence；Qwen 做 semantic policy-compliance audit。

### 4. Source Disposition / Mapping Integrity

重新检查：

```text
∀ CanonicalEvent: exactly one disposition
keep/compress/merge_member → active mapping
omit → no active mapping
```

重大 source omission 不自动 invalid，但必须进入 review surface。

### 5. Adapted Continuity Consistency

检查 story state 是否自相矛盾，例如死亡后无解释地存活、已知秘密后又以“不知道”为前提等。

### 6. Causal / Dependency Closure

检查 hard structured preconditions 与完整 causal path；Qwen 进一步审查 motivation / semantic continuity。

### 7. Reveal / Knowledge Integrity

检查：

```text
world truth
character knowledge
audience knowledge
withholding constraints
```

不得在 EpisodePlan 中提前破坏 B1.4 reveal contract。

### 8. Setup / Payoff Closure

检查重要 payoff 是否有合法 adapted setup path；重要 setup 若不 payoff，应有 intentional ambiguity / red-herring /其它明确 purpose，而不是被遗忘。

### 9. Arc Closure / Distribution

检查 character、relationship、main/subplot arc 是否与 Strategy 一致，并在 episodes 中形成合理 progression / closure 或明确 open ending。

### 10. Episode Partition Integrity

重新 deterministic 验证：

- all primary PE exactly once
- ordering preserved
- contiguous ranges
- no hard no-cut violation
- resolved episode count valid

### 11. Episode Dramatic Integrity

Qwen 以整季视角审查 goal / conflict / climax / hook / opening momentum / dead zones，但只输出 findings，不重新分集。

### 12. Narrative Duration / Budget

验证 narrative planning budget，而不是 backend/H3 generation budget。

保留 estimate uncertainty，可使用：

```text
feasible
feasible_with_risk
infeasible
```

禁止伪精确总时长。

---

## Fidelity / Compression Audit

B1.6 应检查实际 decisions 与 target fidelity/compression policy 是否明显冲突，但不建立虚假的百分比 score。

例如 high-fidelity target 却删除多数 main turning points、改变 ending、合并 primary characters，应产生具体 finding，而不是 `fidelity_score = 73.4%`。

---

## Review Registers

B1.6 必须集中汇总以下高价值 review data：

### Deliberate Divergence Register

所有 `canon_compatibility = deliberate_divergence`，包括重大 fact/timeline/relationship/ending changes。

### Major Omission Register

critical/high-importance event、plot、character、relationship、reveal 的重大删除/简化。

### Invention Register

所有重要 `adaptation_invented` material，按 bridge、externalization、continuity_repair、setup、payoff、dramatic_escalation、deliberate_divergence 等 purpose 汇总。

### Uncertainty / Ambiguity Register

明确区分：

```text
source unresolved
adaptation uncertain
intentional ambiguity
```

Intentional ambiguity 可以合法进入 approval；影响 fundamental continuity 的 adaptation uncertainty 不能。

---

## Finding Severity

冻结 severity：

```text
BLOCKING
REVIEW_REQUIRED
WARNING
```

### BLOCKING

不能进入 approval，例如 dangling IDs、revision mismatch、hard target violation、contradictory continuity、blocking unresolved dependency。

### REVIEW_REQUIRED

结构可成立，但必须人工明确决定，例如 deliberate divergence、critical omission、adapted ending、major character composite、high duration risk。

### WARNING

非 blocking quality concern，例如 soft duration deviation、weak but valid boundary、轻度 arc distribution concern。

---

## Overall Result

冻结：

```text
FAIL
PASS_WITH_REVIEW_ITEMS
PASS
```

语义：

```text
FAIL
= 至少一个 BLOCKING

PASS_WITH_REVIEW_ITEMS
= 无 BLOCKING，但存在 REVIEW_REQUIRED

PASS
= 无 BLOCKING / REVIEW_REQUIRED
```

`PASS != APPROVED`。正式 human approval 只属于 B1.7。

---

## Finding Ownership / Repair Routing

每个 finding 必须标记 earliest authoritative owner stage：

```text
target contradiction → B1.1
global adaptation policy → B1.2
source disposition/mapping → B1.3
story causality/reveal/continuity → B1.4
episode partition/boundary → B1.5
```

原则：

> repair the earliest stage that owns the violated semantic truth

B1.6 自己不 repair。

任何 upstream revision 后，affected downstream B1 stages 与 B1.6 必须重新生成/验证。

---

## AdaptationReviewManifestDraft

B1.6 生成面向 B1.7 的 review projection，至少汇总：

- resolved target summary
- adaptation thesis
- episode count/duration
- major plot/character/relationship decisions
- critical omissions
- character composites
- deliberate divergences
- invented material summary
- ending/reveal changes
- weak/risky boundaries
- duration risks
- remaining uncertainty
- validation warnings

Manifest 只做 review surface，不成为第二份 authoritative truth；其中条目必须引用 authoritative B1 IDs。

---

## Non-goals

B1.6 不检查：

- screenplay 是否符合 EpisodePlan
- shot/asset completeness
- prompt correctness
- H3/ComfyUI feasibility
- generation request identity
- runtime candidate/QC state
- project-wide stale propagation

这些属于后续 architecture layers。

---

## 冻结原则

1. B1.6 是 read-only integrated AdaptationPlan auditor。
2. 只消费 B1.1–B1.5 complete semantic artifacts。
3. 不创造故事、不重新分集、不 silent mutate upstream。
4. ValidationReport 绑定精确 revision/hash input set。
5. 检查 target、strategy、disposition、continuity、causality、reveal、setup/payoff、arc、episode 与 narrative budget 的跨层一致性。
6. Backend/H3/ComfyUI feasibility 不属于 B1.6。
7. 汇总 divergence、major omission、invention、uncertainty。
8. Findings 使用 BLOCKING / REVIEW_REQUIRED / WARNING。
9. 每个 finding 指向 earliest authoritative owner stage。
10. Repair 发生在 B1.1–B1.5；B1.6 只 diagnose + route。
11. Overall result 使用 FAIL / PASS_WITH_REVIEW_ITEMS / PASS。
12. PASS 不等于 APPROVED。
13. B1.6 产生 AdaptationReviewManifestDraft 供 B1.7 使用。
14. B1.6 不实现 future project-wide artifact graph / stale engine。
