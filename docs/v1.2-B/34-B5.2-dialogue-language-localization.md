# B5.2 — Dialogue / Language Localization

状态：**FROZEN**

## 1. 职责

B5.2 在不改变 B2/B3/B4 canonical semantics 的前提下，把 canonical spoken content 转换成某个 release language / locale 的实际可表演语言实现。

正式输出：

```text
EpisodeDialogueLocalizationPlan
```

每个需要语言处理的 canonical utterance 对应：

```text
LocalizedUtterance
```

核心关系：

```text
canonical spoken semantics
↓
LocalizedUtterance
```

而不是从 PlannedShot 自由创作新对白。

## 2. Source authority

B5.2 所读取的 Dialogue / Narration / VoiceOver / OffscreenSpeech 必须通过 `EpisodeReleaseVariantContext` 与 `EpisodeShotPlan` pinned provenance 解析 exact source revision。

每个 `LocalizedUtterance` 至少保存：

```text
source_screenplay_element_id
source_screenplay_revision
source_text_hash
speaker_ref
related_planned_shot_ids
```

禁止使用 `latest screenplay` 或 independently selected source revision。

## 3. LocalizedUtterance identity

概念：

```text
LocalizedUtterance
= canonical utterance × ReleaseVariant
```

`localized_utterance_id` 必须稳定，不绑定：

- localized text content
- subtitle cue number
- audio filename
- display order

同一 canonical utterance 在 zh-CN / en-US 等不同 variant 中可以有不同 LocalizedUtterance。

## 4. 建议结构

```text
LocalizedUtterance
{
  localized_utterance_id
  source_ref
  speaker_ref
  source_language
  target_language
  target_locale
  source_text
  localized_spoken_text
  localization_mode
  semantic_obligations
  performance_constraints
  timing_constraints
  terminology_bindings
  estimated_spoken_duration
  semantic_equivalence_status
  review_flags
}
```

## 5. Localization mode

正式 taxonomy：

```text
DIRECT_TRANSLATION
NATURALIZED_TRANSLATION
PERFORMANCE_ADAPTATION
TIMING_ADAPTATION
LOCALE_ADAPTATION
PRESERVE_SOURCE
```

这些 mode 描述语言 realization strategy，不赋予修改 canonical story semantics 的 authority。

## 6. Semantic fidelity

核心原则：

```text
semantic fidelity > lexical fidelity
```

必须保留：

- speaker intent
- plot information
- character relationship
- emotional meaning
- reveal / concealment semantics
- audience / character knowledge state
- causal meaning
- required ambiguity / certainty

自然化、语序变化和 idiomatic expression 合法；剧情语义漂移不合法。

## 7. UtteranceSemanticObligation

正式引入可结构化的：

```text
UtteranceSemanticObligation
```

可表示诸如：

```text
INFORMATION
INTENT
EMOTION
RELATIONSHIP_SIGNAL
REVEAL
CONCEALMENT
QUESTION
COMMAND
PROMISE
DENIAL
DECEPTION
AMBIGUITY
```

一个 utterance 可有多个 obligations。B5.2 必须使 target-language realization 保持这些 functional semantics。

## 8. Reveal / ambiguity

Localization 不得通过补充主语、专名、解释性 wording 等提前泄露 canonical information。

正式支持：

```text
AmbiguityConstraint
```

例如：

- IDENTITY_AMBIGUITY
- INTENT_AMBIGUITY
- TEMPORAL_AMBIGUITY
- REFERENT_AMBIGUITY
- TRUTH_VALUE_AMBIGUITY

要求 functional ambiguity 等价，不要求相同语法结构。

## 9. Character voice

正式使用 `CharacterVoiceConstraint` 描述 release-localized voice，例如：

- formality
- verbosity
- vocabulary level
- directness
- emotional restraint
- humor style
- speech rhythm
- age appropriateness
- relationship register

B5.2 可以 localize 语言表达，但不能无依据重塑角色 personality / social relationship。

## 10. 称谓 / 关系表达

中文与英文等语言之间的称谓不能仅按 dictionary mapping。

B5.2 必须参考 pinned canonical relationship/context，再决定 name/title/kinship-term/zero-address 等 linguistic realization。

```text
relationship semantics = canonical
linguistic realization = release-specific
```

## 11. LocalizationTerminologyRegistry

正式支持 versioned/pinned：

```text
LocalizationTerminologyRegistry
```

用于 character names、places、organizations、fictional terms、technical terms、titles、catchphrases 等。

条目可声明：

```text
canonical_term
source_language
target_language
preferred_form
forbidden_forms
translate/transliterate/preserve policy
notes
```

Registry 可以 series-scoped；EpisodeDialogueLocalizationPlan 必须 pin exact revision/hash。

## 12. Source snapshot

`LocalizedUtterance` 可以保存 source text snapshot/hash 方便 review，但 source snapshot 不是新的 source of truth。

Authoritative source 仍是 pinned upstream artifact。

## 13. Spoken text 与 subtitle text 分离

正式保持：

```text
localized_spoken_text ≠ subtitle_text
```

B5.2 负责 spoken localization；subtitle realization 在 B5.4。

字幕可以为 readability 做进一步合法压缩，但不能反向成为 canonical spoken text。

## 14. Performance markers

正式支持 semantic `PerformanceMarker`，例如：

```text
PAUSE
HESITATION
STUTTER
INTERRUPTION
OVERLAP
EMPHASIS
WHISPER
SHOUT
```

如果 marker 承担角色/剧情 semantics，localization 不得无条件删除。

对于 interruption / trails-off 等，还应保持 completion semantics，例如：

```text
COMPLETE
INTERRUPTED
TRAILS_OFF
CUT_OFF
```

## 15. Dialogue overlap

如果 canonical screenplay/production 已表达 overlap/simultaneous speech，B5.2 必须保持。

Target language 导致 overlap 无法在 canonical timing 内实现时，应输出 localization/timing conflict，而不是偷偷改为 sequential dialogue。

## 16. Estimated spoken duration

B5.2 必须输出 planning signal：

```text
estimated_spoken_duration
```

它不等于 concrete voice asset 的 measured duration。

结合 B4.5 timing contract，可判定：

```text
FIT
FIT_WITH_REFINEMENT
CONFLICT
```

允许通过自然 wording compression、contraction、无语义 filler cleanup 等调整；不得删除 required information、改变 reveal、换 speaker、移动 utterance 到另一 Shot。

## 17. Timing conflict escalation

建议区分：

```text
LOCALIZATION_REFINEMENT
VARIANT_TIMING_REFINEMENT
CANONICAL_TIMING_CONFLICT
```

如果 wording refinement 与 B5 release timing refinement 仍不能保持 canonical timing/reveal obligations，则：

```text
REQUIRES_B4_REVISION
```

B5.2 不扩大 B4 timing envelope。

## 18. Delivery semantics

B5.2 至少覆盖：

```text
DIALOGUE
VOICE_OVER
NARRATION
OFFSCREEN_SPEECH
```

这些 delivery semantics 来自 upstream。B5.2 不得为了 localization/timing 将 Dialogue 改成 VoiceOver，或把 OffscreenSpeech 改成 visible dialogue。

On-screen visual text 可以建立 dependency，但不在 B5.2 创建第二套 visual asset system。

## 19. Rating / censorship adaptation

Release platform 的 language moderation 不是任意改剧情的 authority。

如需 softening profanity / rating adaptation，必须进行 semantic + character-intensity preservation check；无法保持时至少 `REVIEW_REQUIRED`，必要时 upstream revision。

## 20. Candidate model

Qwen 输出应视为：

```text
LocalizationCandidate
```

可以生成 1..N candidates，并比较：

- semantic fidelity
- naturalness
- character voice
- timing fit

但 canonical `EpisodeDialogueLocalizationPlan` 每个 utterance 只能选择一个正式 realization；alternate final lines 应形成新的 variant/revision，而不是多个同时 authoritative selections。

## 21. Local validation

B5.2 local validation 至少检查：

- source reference integrity
- speaker integrity
- utterance completeness
- semantic-obligation preservation
- reveal safety
- ambiguity preservation
- terminology compliance
- character voice compatibility
- timing compatibility
- performance-marker preservation

Severity 沿用：

```text
BLOCKING
REVIEW_REQUIRED
WARNING
```

Validator 不 silent auto-fix。

## 22. EpisodeDialogueLocalizationPlan

正式 artifact 至少 pin：

```text
EpisodeReleaseVariantContext id/revision/hash
EpisodeShotPlan id/revision/hash
LocalizationTerminologyRegistry revision/hash
```

并包含 selected LocalizedUtterances、conflicts、review items、duration estimates 与 local semantic validation results。

## 23. Asset boundary

B5.2 不绑定：

- concrete WAV
- TTS / voice-clone model
- voice embedding
- sample rate
- audio file path
- H3/ComfyUI node

它只定义：

```text
who speaks
what is spoken
in what target language
with what semantic/performance intent
inside what timing constraints
```

## 24. Python / Qwen

Qwen：

- translation / naturalization
- semantic equivalence
- character voice
- ambiguity preservation
- duration-aware rewriting

Python：

- exact source refs
- candidate/state recording
- identity / revision / hash
- terminology pinning
- schema / structural validation
- deterministic assembly

Qwen 不能修改 source screenplay、speaker、Shot structure、reveal authority 或自行 approve localization。

## 25. 冻结原则

1. B5.2 输出 `EpisodeDialogueLocalizationPlan` 与 selected `LocalizedUtterance`。
2. Source spoken content 必须来自 EpisodeShotPlan pinned lineage。
3. `LocalizedUtterance = canonical utterance × release variant`，identity 与 text/audio file 分离。
4. `semantic fidelity > lexical fidelity`。
5. Reveal、knowledge、ambiguity、character intent/relationship 是硬 semantic constraints。
6. 正式支持 CharacterVoiceConstraint、PerformanceMarker、AmbiguityConstraint。
7. LocalizationTerminologyRegistry 必须可 version/pin。
8. localized spoken text 与 subtitle text 分离。
9. estimated spoken duration 是 planning signal，不等于 measured audio duration。
10. Target-language timing 可以在 B4 envelope 内 refinement；突破 canonical timing semantics 必须 escalation。
11. Delivery mode 不得因 localization silent 改写。
12. Candidate generation 可 non-deterministic；canonical selection/state/hash 必须 deterministic。
13. Local validator 不 silent auto-fix。
14. B5.2 保持 asset-unresolved、backend-agnostic。
15. B5.2 不拥有 Shot split/merge/reorder authority。
