## 2. Necessary narrow contract correction — EntityMap v2

A4A 的 `EntityMap v1` 只保存：

- output artifact refs；
- A3 input identity。

但 frozen A4 reuse contract还要求 pin：

- reconciliation profile id/hash；
- semantic LLM profile id/hash；
- prompt id/version/content hash；
- output schema id/version/hash；
- A4B plan hash；
- exact semantic request hashes。

如果这些 identity 不进入 persisted final authority，则：

```text
same A3 inputs
+
changed profile/prompt/schema/planning semantics
```

无法在 CURRENT reuse 前被可靠区分。

因此 A4D 在第一次真实 persistence 前做一次 narrow schema correction：

```text
EntityMap schema_version: 1 → 2
```

新增内嵌：

```text
A4SemanticIdentity
```

这不是新增第八个 artifact，也不是第二个 bundle manifest。

最终仍然：

```text
EntityMap = sole final aggregate authority
```

A4D 必须同步更新：

- Python `EntityMap` contract；
- `schemas/entity-map.schema.json`；
- A4A contract tests受影响部分。

当前尚无 persisted A4 EntityMap，因此不需要 migration/backward compatibility。


## 9. Graph edges

从 `all_decisions`：

```text
same_entity
→ positive edge

different_entity
→ negative constraint

uncertain
→ ambiguity edge
```

graph 不使用：

- name similarity；
- token overlap；
- descriptors；
- LLM reason text。

这些都不再重新解释。

---

## 10. same_entity components

对 character/location vertices分别构建 deterministic union-find / connected components。

要求：

- same-type only；
- every merge-graph candidate initially a singleton component；
- same edges union endpoints；
- component candidate refs按 CandidateEntityIndex source order排序；
- component identity不得依赖 union operation order。

没有任何 pair 的 singleton candidate仍是合法 component。

---

## 11. different_entity conflict

same-components 构建后，逐条检查 every `different_entity` decision。

如果：

```text
component(left) == component(right)
```

产生 blocking finding：

```text
A4_RECONCILIATION_CONFLICT
```

owner：

```text
A4
```

fail closed。

例如：

```text
A same B
B same C
A different C
```

不得：

- majority vote；
- drop edge；
- prefer LLM；
- prefer deterministic；
- auto repair。

没有 valid canonical outputs被 publish。

---

## 12. uncertain component graph

先 collapse same-components。

对每条 `uncertain` decision：

```text
component(left) ↔ component(right)
```

建立 component-level undirected ambiguity edge。

如果 uncertain 的两端已在同一 same-component：

```text
self ambiguity
```

该 component仍视为 **incident to uncertainty**，因此 unresolved。

这是 precision-first 行为，不是 graph conflict。

---

## 13. uncertain connected groups

在 component-level uncertain graph 中：

- 每个 incident component是 vertex；
- uncertain edges决定 connected groups；
- 一个 group可包含 1+ same-components；
- group中所有 merge-graph candidate均 unresolved；
- group不产生 canonical ID。

`different_entity` edges不参与 uncertain connectivity。

一个 uncertain group内部可以存在 known-different relation；这不是 contradiction：

```text
unresolved group = ambiguity cluster
not equivalence class
```

global `ReconciliationDecisionSet` 保留所有 same/different/uncertain decisions。

---

## 14. Uncertain-group decision_refs

A4 uncertain group的：

```text
decision_refs
```

只包含形成该 ambiguity connected group的：

```text
uncertain decision_id
```

要求：

- unique；
- canonical lexical order。

same/different decision仍可通过 global ReconciliationDecisionSet审计，不复制到 unresolved group。

---

## 15. Resolved components

任何 merge-graph same-component如果：

```text
not incident to any uncertain edge
```

则 resolved。

`different_entity` edge不会阻止 component自身成为 canonical entity；它只约束不同 components不得 collapse。

因此：

```text
not_compared singleton
→ resolved singleton canonical entity
```

符合 frozen A4 v1 semantics。

## 16. Stable canonical IDs

Character components 和 location components分别编号。

排序 key：

```text
(
  earliest member source_order_key,
  earliest member candidate_ref
)
```

Character：

```text
char_0001
char_0002
...
```

Location：

```text

loc_0002
...
```

要求：

- gap-free；
- start at 1；
- separate namespaces；
- independent of graph traversal / dict / set order。

## 17. CanonicalEntity construction

一个 resolved component：

```text
candidate_refs
```

按 source order。

```text
first_appearance_candidate_ref
```

= first candidate ref。

```text
display_name_original
```

= earliest candidate的 original display name。

```text
aliases_original
```

= component candidates按 source order依次展开：

```text
display_name_original
then aliases_original
```

进行 exact-string ordered union。

不：

- normalize存储值；
- translate；
- synthesize新的 name；
- summarize descriptors。

这保持 frozen implementation contract的 “source-order union of names + aliases”。

## 18. A3 unresolved passthrough

每个 A3 unresolved index entry独立形成一个 UnresolvedEntity。

不与其它 A3 unresolved自动 group。

mapping：

```text
unresolved_person   → person
unresolved_location → location
unresolved_unknown  → unknown
unresolved_other    → other
```

字段：

```text
candidate_refs = (self candidate_ref,)
decision_refs = ()
possible_candidate_refs = exact indexed possible refs
first_appearance_candidate_ref = self candidate_ref
```

不得猜测 possible refs中的某一个 canonical target。

---

## 19. A4 uncertain UnresolvedEntity

每个 uncertain connected group形成一个 UnresolvedEntity：

```text
entity_kind = character | location
candidate_refs = all member candidate refs in source order
decision_refs = uncertain decision IDs
possible_candidate_refs = ()
first_appearance_candidate_ref = earliest member
```

由于 A4 pair只 same-type，因此一个 uncertainty group不得混 character/location。

若出现混 type：

```text
fail closed
```

## 27. Shared A4 revision

一个 successful A4 publication的六个 A4 artifacts + ValidationReport使用同一个：

```text
run_revision
```

revision allocator：

1. start：
   - no CURRENT → 1；
   - current EntityMap revision + 1；
2. 检查该 revision是否在 **任一** A4 logical artifact / validation report slot已存在；
3. 如果任一存在，revision += 1；
4. 直到整组 slot free。

原因：

- failed CAS可能留下 orphan immutable artifacts；
- 下一次 publication不得 overwrite；
- shared revision让 coherent run容易 audit。

## 34. Post-provider publication race

`publish_validated` 在真正写新 revision前重新读取/验证 CURRENT。

如果 provider执行期间另一个 writer已经把 **same requested identity** 发布为 CURRENT：

```text
reuse that CURRENT
do not create duplicate publication
```

如果变成 different identity：

- fully verify；
- 继续以该 latest CURRENT作为 expected CAS base；
- publish new revision。

若 CURRENT corrupt：

```text
fail closed
```

## 35. Persistence ordering

在任何 A4 artifact write前：

```text
build all graph/final outputs in memory
→ deterministic validation
→ require zero blocking findings
```

然后：

```text
persist CandidateEntityIndex
→ persist ReconciliationDecisionSet
→ persist CanonicalCharacterRegistry
→ persist CanonicalLocationRegistry
→ persist UnresolvedEntitySet
→ build/persist EntityMap v2 with exact persisted refs
→ build/persist exact A4 ValidationReport
→ reload/verify report PASS
→ compare-and-set A4 CURRENT to EntityMap
```

若 CAS失败：

```text
CURRENT unchanged
immutable artifacts remain historical/orphaned
```

下一 revision allocator必须跳过这些 slots。
