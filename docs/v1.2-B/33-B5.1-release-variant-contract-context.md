# B5.1 — Release Variant Contract + Variant Context

状态：**FROZEN**

## 1. 职责

B5.1 建立 Release Variant 阶段的 semantic firewall，并把一个 exact `APPROVED EpisodeShotPlan` 与具体 release target 绑定成 deterministic `EpisodeReleaseVariantContext`。

核心定义：

```text
EpisodeShotPlan
= canonical shot/editorial semantics

EpisodeReleaseVariant
= constrained release-specific realization
```

Release Variant 可以 refinement presentation，但不能重新解释 canonical Shot Plan。

## 2. 正式输入

B5.1 只允许正式消费 exact `APPROVED EpisodeShotPlan`。

必须 pin：

```text
episode_shot_plan_id
episode_shot_plan_revision
episode_shot_plan_hash
shot_plan_approval_record_id
```

禁止通过 `latest/current/default` implicit selector 形成 canonical context。

如果 B5 需要读取 Screenplay / ProductionPlan 等 upstream semantic material，必须通过 EpisodeShotPlan 已固定 provenance 解析 exact upstream revision；B5 不得独立选择另一个 upstream revision。

## 3. ReleaseVariantContract

正式引入：

```text
ReleaseVariantContract
```

它定义某类 release variation 允许改变什么、必须保持什么、何时必须 escalation。

核心原则：

```text
Release variation may refine presentation,
but must preserve canonical shot meaning.
```

## 4. EpisodeReleaseVariantContext

正式输出：

```text
EpisodeReleaseVariantContext
```

建议至少包含：

```text
context_id
revision
content_hash
source_episode_shot_plan_ref
release_variant_identity
release_target_profile
localization_profile
frame_profile
subtitle_profile
audio_localization_profile
release_constraints
lineage_resolution_manifest
semantic_preservation_contract
```

它是 deterministic derived artifact。

同一 approved ShotPlan + 同一 exact release/profile inputs 应得到同一个 semantic context content。

## 5. ReleaseVariantIdentity

Release Variant identity 必须结构化，不得简单依赖 filename 或 slug。

可以由以下维度构成：

- episode identity
- spoken language / locale
- frame profile / aspect-ratio target
- platform profile
- subtitle profile
- audio localization profile

必须保持：

```text
variant identity ≠ filename
variant identity ≠ export name
variant identity ≠ revision
```

同一 variant identity 可以有多个 revisions。

## 6. ReleaseTargetProfile

正式使用结构化 `ReleaseTargetProfile` 描述目标发行环境，例如：

```text
target_locale
spoken_language
subtitle_language(s)
frame_aspect_ratio
distribution_platform
subtitle_delivery_mode
audio_localization_mode
release_duration_constraints
safe-area requirements
```

具体 encoder resolution / codec / bitrate 不属于 B5 canonical semantics。

## 7. B5 不拥有的 authority

B5 不得 silent 修改：

- PlannedShot identity
- Shot ordering
- ProductionUnit ownership
- PRIMARY/SUPPORTING PCR mapping
- Shot purpose
- reveal authority / audience knowledge state
- canonical viewpoint / orientation / camera angle / movement intent
- editorial Shot boundaries
- canonical continuity / transition semantics
- B4 timing anchors
- B4 generation-segmentation policy

如果 release target 只能通过这些 canonical changes 才能满足，则必须 explicit escalation。

## 8. Variation classification

正式区分：

```text
SAFE_REFINEMENT
CONSTRAINED_REFINEMENT
CANONICAL_CHANGE
```

### SAFE_REFINEMENT

典型包括：

- 合法目标语言表达
- subtitle style/layout policy 的非语义调整
- platform metadata
- render-only configuration

前提是 canonical semantic obligations 不变。

### CONSTRAINED_REFINEMENT

典型包括：

- 9:16 / 16:9 framing realization
- spoken-duration adaptation
- subject repositioning inside allowed staging semantics
- subtitle-safe composition
- release timing refinement
- generation seam candidate refinement within B4 contract

必须通过 semantic-preservation validation。

### CANONICAL_CHANGE

例如：

- add/remove/split/merge/reorder PlannedShot
- change PRIMARY PCR
- change Shot purpose
- change reveal authority
- change POV/viewpoint semantics
- change editorial cut
- change canonical timing-anchor semantics

B5 无 authority，必须回 B4 或更早 upstream。

## 9. Aspect ratio 原则

B4.3 定义 semantic composition，而不绑定 aspect ratio / pixel coordinates。

因此 B5 可以针对 9:16、16:9、1:1 等产生不同 release framing realization，但必须继续满足：

- primary attention
- required visibility
- required co-visibility
- reveal timing
- viewpoint / orientation / angle semantics
- continuity obligations

如果 portrait frame 无法保持 canonical simultaneous co-visibility，B5 不得把一个 PlannedShot 偷拆成多个 Shot；必须 route 到 B4。

## 10. Language / localization 原则

Localization 可以进行：

- translation
- naturalization
- idiomatic adaptation
- performance-aware wording
- timing-aware wording compression/expansion

但不得改变：

- plot facts
- character intent
- relationship semantics
- reveal / concealment
- knowledge state
- required ambiguity
- narrative causality

正式原则：

```text
semantic equivalence > literal equivalence
```

## 11. Spoken duration

B5 可以在 B4.5 `ShotTimingSpecification` 允许的 semantic timing envelope 内实现不同语言时长。

若 localized speech 可以通过 wording / legal hold refinement 放入 envelope，则属于 B5。

如果必须改变：

- editorial Shot structure
- reveal placement
- canonical timing anchor
- required reaction timing

则必须回 B4。

## 12. Subtitle / platform / render 边界

Subtitle text/layout、safe area、platform-specific framing 属于 release concern，但不得覆盖 canonical semantics。

B5 不把最终 pixel coordinates、font rasterization、ASS styling、codec 等变成 canonical release truth。

Render-only change 在不改变 semantic artifact 的前提下不要求重新 B4/B5 approval。

## 13. classify_variant_change

实现层最终应有 deterministic/semantic combined classification，概念结果：

```text
SAFE_REFINEMENT
CONSTRAINED_REFINEMENT
REQUIRES_B4_REVISION
```

必要时进一步 route：

```text
B5 refinement
B4 Shot redesign
B3 production staging revision
earlier upstream revision
```

B5 不得 silent fallback。

## 14. Lineage resolution

`EpisodeReleaseVariantContext.lineage_resolution_manifest` 应记录本 variant 实际读取的 exact upstream semantic sources。

这些 refs 必须来自 EpisodeShotPlan provenance，不得独立 repin。

原则：

```text
B5 may read lineage-resolved upstream artifacts,
but may not independently select upstream revisions.
```

## 15. Python / Qwen

Python：

- resolve exact approved ShotPlan
- resolve pinned upstream lineage
- validate profile refs
- build deterministic context
- classify structural authority boundaries
- IDs / revisions / hashes / provenance

Qwen：

- semantic localization reasoning
- framing reasoning
- timing-fit reasoning
- conflict diagnosis

Qwen 不能选择 source revision、修改 canonical ShotPlan 或自行批准 release variation。

## 16. 冻结原则

1. B5 正式输入必须是 exact APPROVED EpisodeShotPlan。
2. `EpisodeShotPlan` 是 canonical semantic authority；Release Variant 只允许 constrained refinement。
3. 正式输出 `EpisodeReleaseVariantContext`，并使用 `ReleaseVariantContract`。
4. B5 可以通过 ShotPlan provenance 读取 exact upstream semantic material，但不能 independently repin upstream。
5. ReleaseVariantIdentity 结构化，并与 filename/revision 分离。
6. ReleaseTargetProfile 描述 language/frame/platform/subtitle/audio target；encoder/backend 参数不进入 canonical contract。
7. Variation 分为 SAFE_REFINEMENT / CONSTRAINED_REFINEMENT / CANONICAL_CHANGE。
8. PlannedShot structure、PRIMARY PCR、Shot purpose、reveal、canonical camera/editorial semantics 不得因 release silent 修改。
9. 9:16/16:9 adaptation 本身不要求 B4 reapproval，但必须 preserve canonical obligations。
10. Localization 以 semantic equivalence 为核心，不要求 literal equivalence。
11. Spoken duration 可在 B4 timing envelope 内 refinement；突破 canonical timing semantics 必须回 B4。
12. B5 不绑定 concrete assets / H3 / ComfyUI / ProductionShot。
13. Render-only change 与 semantic release change 分离。
14. 无法满足 release target 时必须 explicit conflict + resolution authority，禁止 silent fallback。
15. `EpisodeReleaseVariantContext` 是 deterministic derived artifact。
