# B3.6 — Episode Production Plan Assembly

状态：**FROZEN**

## 1. 职责

B3.6 是 deterministic canonical production assembly stage。

它只把 B3.5 已验证的 exact bundle materialize 为：

```text
EpisodeProductionPlan
```

B3.6 不继续进行 production semantic design。

## 2. Canonical artifact

`EpisodeProductionPlan` 是 versioned structured production artifact，不是 Markdown/PDF、Shot list、generation job、asset manifest 或 ComfyUI workflow。

概念上包含：

- production_plan_id / revision / content_hash
- exact approved screenplay pin
- exact validated bundle pin
- ordered ProductionUnit manifest
- requirement identities / unit uses
- staging / performance refs
- perceptual obligations
- production continuity composition
- duration / complexity summaries
- provenance manifest
- EpisodeProductionEndingCheckpoint

## 3. validated bundle binding

B3.6 只允许消费 `ProductionValidationReport` result = PASS 或 PASS_WITH_REVIEW_ITEMS，并必须满足：

```text
EpisodeProductionPlan.source_validated_bundle_hash
=
ProductionValidationReport.validated_bundle_hash
```

必须 pin exact B3.2/B3.3/B3.4/constraint-profile revisions/hashes；禁止 implicit latest。

若任何 constituent drift，即使 ID/revision 未正确 bump 但 hash 改变，B3.6 fail closed。

## 4. Screenplay pin

Plan 顶层必须保留：

```text
episode_screenplay_id
episode_screenplay_revision
episode_screenplay_hash
screenplay_approval_record_id
```

ProductionPlan provenance 因此可继续回溯到 B1/source，但无需复制整个 upstream truth。

## 5. ProductionUnit manifest

正式保存有序 `ProductionUnitAssemblyEntry[]`，保留 B3.2 order、screenplay coverage、requirement-set、execution-plan、continuity references。

B3.6 不得增加、删除、split、merge、reorder ProductionUnit。

Requirement / StagingDirective / PerformanceRequirement / PerceptualCoverageRequirement identity 在 assembly 中保持，不重新编号为另一套语义对象。

## 6. EpisodeProductionPlan ≠ RenderedProductionPlan

正式区分：

```text
EpisodeProductionPlan
= canonical structured artifact

RenderedProductionPlan
= deterministic derived review/display view
```

Renderer 只能做 non-semantic formatting/display normalization，不得丢失或重写 REQUIRED obligation。

## 7. Production continuity composition

Python 按 canonical ProductionUnit sequence deterministic compose：

```text
episode opening production state
+ PU001 delta
+ PU002 delta
+ ...
= episode ending ProductionContinuityState
```

正式产生 derived：

```text
EpisodeProductionEndingCheckpoint
```

它只保存下一集可能依赖的 sparse persistent production state；不得成为 narrative truth source。

只有最终 APPROVED ProductionPlan 的 checkpoint 才能成为 downstream 正式 production-continuity dependency。

## 8. Derived indexes

B3.6 可以 deterministic 生成：

- `ProductionRequirementIndex`
- `PerceptualCoverageIndex`
- `PerformanceObligationIndex`

用于 downstream Asset Resolution / Shot Planning。

Asset Resolution 不重新从 screenplay 猜 requirements；Shot Planning 不重新决定 narrative importance。

## 9. Duration / complexity

B3.6 聚合 unit duration/complexity metadata，但不修改 constituent semantics。

```text
production duration estimate
≠ Shot duration
≠ H3 clip length
≠ final edit duration
```

Complexity metrics 不是 quality score。

## 10. Revision / immutability

`EpisodeProductionPlan` 拥有独立 id/revision/content_hash。

任何 B3.2/B3.3/B3.4/constraint semantic revision、manifest、requirements、staging/performance/perceptual obligation、continuity semantic 变化均产生新 plan revision。

Render-only format change不产生 semantic revision。

已创建 plan revision immutable。

## 11. Validation binding / lifecycle entry

Plan 必须保存：

```text
production_validation_report_id
production_validation_report_hash
source_validated_bundle_hash
```

PASS_WITH_REVIEW_ITEMS 可以生成 DRAFT plan 并携带 unresolved review-item refs；B3.6 不能自行 ACCEPT_AS_DESIGNED。

B3.5 FAIL 不得产生 approval-eligible EpisodeProductionPlan。

新 Plan 默认 `DRAFT`；B3.6 不产生 APPROVED state。

## 12. Non-goals / roles

B3.6 不绑定 concrete asset、H3/ComfyUI/GPU/runtime job，也不决定 actual generation/shooting schedule。

正常 assembly 由 Python deterministic 执行；Qwen 最多生成 derived human-readable explanation，不得修改 canonical semantics。

B3.6 只做 assembly integrity validation，不重复 B3.5 semantic adjudication。

## 13. 冻结 contract

1. B3.6 deterministic assembly exact B3.5 validated bundle。
2. 正式引入 canonical versioned `EpisodeProductionPlan`。
3. Plan 保存 `source_validated_bundle_hash` 与 exact validation report。
4. exact pin B3.2/B3.3/B3.4/constraint profile，禁止 latest。
5. Plan 顶层 pin exact APPROVED screenplay。
6. 不增加/删除/split/merge/reorder ProductionUnit。
7. constituent semantic identities 保持稳定。
8. `EpisodeProductionPlan ≠ RenderedProductionPlan`。
9. deterministic compose ProductionContinuityDelta chain。
10. 正式生成 sparse derived `EpisodeProductionEndingCheckpoint`。
11. 只有 APPROVED plan checkpoint 可作为正式 downstream production continuity dependency。
12. 可生成 requirement/perceptual/performance derived indexes。
13. Asset Resolution / Shot Planning 消费 approved production semantics，不重新提取上游重要性。
14. Plan 拥有独立 revision/hash，semantic change new revision，旧 revision immutable。
15. PASS_WITH_REVIEW_ITEMS 可形成 DRAFT；FAIL 不形成 approval-eligible plan。
16. 新 Plan 默认 DRAFT，B3.6 不 approve。
17. normal assembly 由 Python deterministic 执行。
18. constituent hash drift 时 fail closed。
19. ProductionSequence 与 actual execution schedule 分离。
20. 不绑定 concrete asset/backend/runtime/Shot。
21. B3.6 无 formal human gate；B3.7 是唯一正式 Production approval gate。
