# 1. 目标

A6 在 A1–A5 已经建立可靠 canonical evidence 之后，把：

- canonical characters；
- canonical locations；
- canonical facts；
- canonical events；
- canonical relationships；
- relationship state histories；
- state transitions；
- source/story conflicts；
- unresolved entities；

提升为整本小说的 **global story interpretation**。

核心边界：

```text
A1–A5 = reliable canonical evidence
A6     = global story understanding / interpretation
B1+    = adaptation decisions
```

A6 最终产生：

```text
canonical evidence
→ hierarchical global analysis
→ GlobalStoryBible
```

A6 允许解释：

- character role / goal / motivation；
- character arc；
- relationship arc；
- plot structure；
- main / secondary conflicts；
- turning points；
- reveals；
- foreshadow / payoff；
- themes；
- global event importance；
- ending state；
- full-story synopsis。

A6 不允许做：

- 删除哪些 source story 内容；
- 合并哪些 source events 作为 adaptation；
- 改成多少集；
- 每集 cliffhanger；
- screenplay；
- production planning；
- shot planning；
- asset resolution；
- H3 / ComfyUI generation decisions。

这些属于 B1+。

## User creative guidance boundary

A6 不消费 user creative/adaptation guidance。

即使用户已经表达了：

- 想删减哪些剧情；
- 想强化/弱化哪些角色；
- 想修改人物外形或衣着；
- 想改变对白、动作、blocking；
- 想指定镜头、构图或 camera 风格；

A6 仍只负责回答“source story 是什么、全局如何理解”。

正式 user-directed creative steering 从 B1 或更晚的 authoritative owner stage 开始，并通过独立的 versioned User Direction / Revision Guidance contract 进入 downstream semantic identity、revision 与 provenance。

因此：

```text
A6 GlobalStoryBible
= source-grounded global understanding

UserDirection
= downstream creative intent

两者不得合并成同一 authority
```

# 41. Reuse miss vs corruption

Normal miss：

- no A6 CURRENT；
- upstream A5 manifest changed；
- A6 profile changed；
- prompt/schema changed；
- deterministic planning changed；

# 63. Frozen implementation decisions

以下 implementation decisions 已冻结：

1. A6 exact input authority = validated CURRENT A5 `ConsolidationManifest`。
2. A6 root publication authority = `StoryAnalysisManifest`。
3. A6 CURRENT 指向 exact validated `StoryAnalysisManifest`。
4. 保留五个 semantic leaf outputs：CharacterAnalysisSet、GlobalEventAnalysis、ArcAnalysis、GlobalStructure、GlobalStoryBible。
5. A6 新 canonical analysis IDs全部由 Python deterministic 分配。
6. Plot windows使用 exact-one core ownership + context overlap。
7. explicit evidence 与 inferred interpretation在 schema层显式区分。
8. Window/token numeric planning policy必须经过 Alice zero-provider audit后冻结。
9. A6 v1 whole-stage current-only reuse；不做 partial-pass cache。
10. Fresh A6 build在内存完成全部 passes，成功后 coherent publication。
11. A6 semantic identity backend-neutral；runtime NP/slots/concurrency不进入 identity。
12. A6G默认只做一次 Alice fresh real-provider full run + zero-call reuse，不机械做第二次 artificial-invalidation full run。
13. `build-story-bible` 作为 A6 stage CLI；`analyze-story` 作为 A1→A6 wrapper。
14. A6 v1不实现 autonomous RAG/vector DB；source expansion仅允许 deterministic provenance-based policy。
15. A6C/D concurrency不是 correctness prerequisite；如实现则只属于 runtime execution policy。

以上 decisions 作为 A6 implementation planning 与 A6A–A6G child issue decomposition 的 authoritative baseline。
