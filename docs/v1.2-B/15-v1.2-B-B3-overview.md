# v1.2-B / B3 — Production Planning 总览

状态：**FROZEN**

## 1. 目标与边界

B3 将一个已经批准的 `EpisodeScreenplay` 转换为可供 Shot Planning 消费的 production-semantic contract。

```text
B2 = 戏怎么写
B3 = 这场戏在制作层面需要怎样被执行
Shot Planning = 用哪些具体镜头覆盖这个执行方案
```

因此：

```text
ScreenplayScene ≠ ProductionUnit ≠ Shot
```

B3 不重新定义 screenplay / adaptation truth，不绑定具体图片、WAV、LoRA、H3 reference、ComfyUI workflow、GPU/runtime job，也不生成 camera/lens/framing/shot list。

## 2. B3 完整结构

```text
B3.1 Production Contract / Episode Production Context
B3.2 Production Scene Breakdown
B3.3 Production Requirements
B3.4 Staging + Performance + Coverage Requirements
B3.5 Production Continuity / Feasibility Validation
B3.6 Episode Production Plan Assembly
B3.7 Production Review + Approval Gate
```

完整链：

```text
APPROVED EpisodeScreenplay
↓
EpisodeProductionContext
↓
EpisodeProductionBreakdown
↓
EpisodeProductionRequirements
↓
EpisodeStagingPerformancePlan
↓
ProductionValidationReport
↓
EpisodeProductionPlan
↓
ProductionApprovalRecord
↓
APPROVED EpisodeProductionPlan
↓
Shot Planning
```

## 3. 核心 artifact

- `EpisodeProductionContext`：从 approved screenplay deterministic 构建的 derived context。
- `ProductionUnit`：production execution unit，不是 screenplay scene 或 shot。
- `EpisodeProductionBreakdown`：有序 ProductionUnit decomposition。
- `ProductionRequirement`：production 必须/应该满足的 semantic requirement，不是 concrete asset。
- `EpisodeProductionRequirements`：episode-level requirement catalog + unit uses。
- `ProductionUnitExecutionPlan`：某个 ProductionUnit 的 staging / performance / perceptual realization contract。
- `EpisodeStagingPerformancePlan`：完整 episode 的 execution planning artifact。
- `ProductionValidationReport`：B3.5 read-only integrated audit artifact。
- `EpisodeProductionPlan`：canonical versioned production-planning composition。
- `ProductionApprovalRecord`：B3.7 human approval artifact。

## 4. Continuity 分层

```text
Adapted Continuity
= narrative truth

Screenplay Continuity
= screenplay realization overlay

Production Continuity
= visible / performative / staging overlay
```

Production Continuity 不得覆盖上游 narrative/screenplay truth，只保存 downstream execution 真正依赖的 sparse state。

## 5. Requirement / Asset / Shot 分层

```text
ProductionRequirement
= production 需要什么

Asset Resolution
= 哪个 concrete asset 满足 requirement

PerceptualCoverageRequirement
= 观众必须感知/理解什么

Shot Planning
= 用什么 camera/audio coverage 实现 perceptual obligation
```

因此 B3 保持 model/backend agnostic。

## 6. Production invention 边界

B3 可以增加无 narrative consequence 的 production realization detail，例如普通站位、走位、generic support prop、background behavior。

如果 production detail 改变 screenplay fact、knowledge、relationship、causality、object possession、scene outcome 或 future dependency，则必须 route 回 B2；若进一步改变 adaptation truth，则 route 回 B1。

## 7. Validation / assembly / approval

```text
B3.5 = read-only verify / diagnose / route
B3.6 = deterministic canonical assembly
B3.7 = 唯一正式 human approval gate
```

B3.5 验证 exact production candidate bundle，并产生 `validated_bundle_hash`；B3.6 只能 exact materialize 该 bundle，不能改变 semantics。

只有 `APPROVED EpisodeProductionPlan` 才允许 Shot Planning 正式消费。

## 8. Python / Qwen / Human

```text
Python
```
