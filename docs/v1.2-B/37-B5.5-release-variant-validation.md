# B5.5 — Release Variant Validation

状态：**FROZEN**

## 1. 职责

B5.5 是 B5 的 **read-only integrated auditor**。

它不生成新的 localization、framing 或 timing 设计，也不修复问题。它只验证：

```text
这个 exact Release Variant bundle
是否忠实保留 APPROVED EpisodeShotPlan 的 canonical semantics，
并且内部彼此一致、可进入正式 assembly？
```

正式输出：

```text
ReleaseVariantValidationReport
```

## 2. 与 B4.6 的分工

```text
B4.6
= Is the canonical Shot Plan internally valid?

B5.5
= Does this release-specific realization
  preserve that approved canonical Shot Plan?
```

B5.5 不重新审判 ShotPlan 本身好坏；若 release realization 暴露 upstream contradiction，只能报告并 route 到拥有 authority 的上游阶段。

## 3. Exact validated bundle

正式引入：

```text
validated_release_variant_bundle_hash
```

验证对象必须是 fully resolved exact bundle：

```text
APPROVED EpisodeShotPlan
+
EpisodeReleaseVariantContext
+
EpisodeDialogueLocalizationPlan
+
EpisodeReleaseFramingPlan
+
EpisodeReleaseTimingPlan
+
applicable release/localization/profile registries
```

必须 pin 所有 id/revision/hash/approval refs。

禁止 `latest/current/default/active` unresolved selector 进入正式 validation graph。

## 4. Validation result / severity

正式 result：

```text
FAIL
PASS_WITH_REVIEW_ITEMS
PASS
```

Severity：

```text
BLOCKING
REVIEW_REQUIRED
WARNING
```

`FAIL` 不得进入 B5.6。

`PASS_WITH_REVIEW_ITEMS` 可进入 B5.6，但所有 REVIEW_REQUIRED 必须在 B5.7 formal disposition。

## 5. Read-only / no silent repair

B5.5 可以：

```text
detect
compare
diagnose
classify
trace provenance
identify repair authority
```

不得：

- rewrite dialogue
- select another localization candidate
- modify subtitle
- reframe Shot
- change timing/hold
- change profile
- modify EpisodeShotPlan

```text
validation ≠ repair
```

Finding 可以有 suggested_resolution_notes，但不能携带 authoritative corrected bundle。

## 6. Validation domains

正式覆盖至少：

```text
revision/reference integrity
approved ShotPlan lineage integrity
variant context integrity
localization semantic fidelity
terminology consistency
reveal / knowledge preservation
character voice / performance preservation
framing semantic preservation
continuity preservation
release timing preservation
subtitle semantic/timing integrity
audio semantic continuity
generation segmentation compatibility
cross-B5 consistency
completeness
unauthorized canonical change
architecture-boundary leakage
release-constraint compatibility
```

## 7. Reference / bundle integrity

检查：

- all refs resolve
- revision/hash exact match
- same episode / same release variant
- no stale dependency
- B5.2/B5.3/B5.4 all derive from same EpisodeShotPlan lineage
- all applicable profiles/registries exact pin

任何 constituent revision mismatch 都是 blocking；不能因为内容“看起来一样”放行。

## 8. Approved ShotPlan lineage integrity

B5.5 必须确认：

```text
source EpisodeShotPlan.status == APPROVED
```

且其 id/revision/hash/ShotPlanApprovalRecord 与 B5.1 pin 完全一致。

B5.2/B5.3/B5.4 不得混用不同 ShotPlan revisions。

## 9. Variant context integrity

ReleaseVariantIdentity / target locale / aspect ratio / subtitle mode / platform profile 等必须与 downstream constituents 实际内容一致。

例如 context 声明 9:16，但 B5.3 target frame 是 16:9，应 BLOCKING。

Variant identity 必须描述 actual assembled variant，而不是仅作为标签。

## 10. Localization semantic fidelity

B5.5 检查 selected localization，而不是 candidate pool。

必须验证：

- canonical information
- speaker intent
- emotional meaning
- relationship semantics
- causal meaning
- speech-act function
- required uncertainty/certainty
- reveal/concealment

Validation 不要求 literal translation；核心仍是 `semantic fidelity > lexical fidelity`。

## 11. Cross-modal reveal / knowledge preservation

Reveal preservation 必须跨：

```text
localized language
visual framing
subtitle timing
release/audio timing
```

整体检查。

单独 B5.2/B5.3/B5.4 local PASS 不代表 integrated reveal PASS。

B5.5 可 deterministic/semantic derive `AudienceKnowledgeInvariant` 用于检查 release variant 是否让观众在 narratively material 的位置过早或过晚获得 canonical information。

Early subtitle reveal、framing 露出未授权身份等均可成为 BLOCKING。

## 12. Ambiguity preservation

如果 canonical ambiguity 有剧情功能，B5.5 必须检查整个 variant 是否仍保持 functional ambiguity。

Dialogue 保持歧义但 subtitle 加明确主语，或 framing 提前显示身份，都应失败。

## 13. Terminology consistency

检查 proper nouns、titles、organizations、fictional terms、recurring catchphrases 是否符合 pinned `LocalizationTerminologyRegistry`。

身份/剧情语义改变可 BLOCKING；风格不一致可 REVIEW_REQUIRED/WARNING。

## 14. Character voice / performance

跨整集检查：

- register drift
- verbosity/directness drift
- age-inappropriate wording
- relationship-register inconsistency
- canonical pause/hesitation/interruption/overlap preservation

单句自然不代表整集角色声音一致。

## 15. Framing semantic preservation

独立 audit B5.3 对 B4.3 的 preservation：

- primary attention
- required visibility
- required co-visibility
- PRIMARY PCR realization
- shot-scale semantic function
- viewpoint
- orientation
- camera angle
- movement
- attention progression
- focus transition

B5.5 不只相信 B5.3 自报 `PRESERVED`。

## 16. PRIMARY PCR preservation

Release realization 后，每个 PlannedShot 仍必须真正实现其 PRIMARY coverage obligations。

PCR 可以被 language/framing/timing 任一 modality 破坏；因此必须 integrated check。

## 17. Perceptual visibility / co-visibility

```text
technical presence ≠ semantic visibility
```

Required subject 即使存在于 frame 中，如果小到不可读，也可能 violation。

同样：

```text
A visible at t1 + B visible at t2
≠ required simultaneous co-visibility
```

## 18. Continuity preservation

必须检查 B4.4：

- InteractionAxis / AxisSide
- eyeline
- screen direction
- entrance/exit direction
- match-on-action
- continuity reset
- transition semantics

Horizontal flip 是高风险 transform，不能按 render-only 默认安全。

## 19. Timing preservation

B5.5 检查：

```text
release duration within canonical numeric envelope
+
canonical timing semantic function preserved
```

数字 within range 不代表 automatically valid。

必须继续检查 timing anchors、reaction/reveal/cut relationships、pacing function 与 transition timing。

## 20. Subtitle integrated validation

至少检查：

- semantic completeness
- reading feasibility
- cue order/overlap
- reveal safety
- ambiguity preservation
- speaker attribution
- timing compatibility
- framing/safe-area compatibility

Subtitle 不需要等于 spoken transcript，但必须满足 release subtitle semantic contract。

## 21. Audio semantic continuity

检查：

- spoken utterance coverage
- narration / voice-over / offscreen delivery role
- required audio bridge
- required overlap
- continuity role

Required audio event 不得 silent disappear。

Audio timing 与 subtitle timing 还需要交叉检查，尤其 reveal ordering。

## 22. Generation segmentation compatibility

B5.5 验证 B5.4 faithful inherit：

```text
SINGLE_PREFERRED
SPLIT_ALLOWED
SPLIT_DISCOURAGED
SPLIT_FORBIDDEN
```

以及 safe candidates / forbidden regions / seam continuity requirements。

B5 不得放宽 B4 segmentation contract。

## 23. Cross-B5 consistency

这是 B5.5 的核心价值：

```text
B5.2 local PASS
+
B5.3 local PASS
+
B5.4 local PASS
≠
B5.5 integrated PASS
```

例如：

- localized speech + subtitle hold 合起来超出 B4 envelope
- framing 单独合法，但与 subtitle safe area 组合遮挡 required object
- dialogue 保持 ambiguity，但 framing 露出 identity

都必须在 B5.5 发现。

## 24. Completeness / orphan detection

必须保证：

- every PlannedShot has framing specification
- every PlannedShot has release timing specification
- every required spoken utterance has selected localization
- subtitles enabled 时 required content 有 cue coverage
- required audio bridges/events有 realization

禁止 `missing = downstream default`。

同时检测：

- unknown PlannedShot refs
- orphan localized utterance
- orphan subtitle cue
- audio event without semantic source

## 25. Unauthorized canonical change

B5.5 应直接比较 approved EpisodeShotPlan 与 B5 realization，检测：

- Shot add/remove/reorder/split/merge
- PCR mapping change
- PRIMARY meaning change
- viewpoint/movement change
- transition type change
- timing-anchor rewrite
- segmentation-policy change

结果：

```text
BLOCKING
UNAUTHORIZED_CANONICAL_CHANGE
```

“看起来等效”不能赋予 B5 改写 canonical contract 的 authority。

## 26. Architecture boundary leakage

Canonical B5 artifacts 不应把以下内容变成 source of truth：

- H3 prompt/node
- ComfyUI workflow/node id
- seed/sampler
- concrete image/WAV path
- Picture N
- ProductionShot
- backend clip limit

检测到这种 authority leakage 应报告 `ARCHITECTURE_BOUNDARY_LEAKAGE`；canonical schema 应尽量直接禁止。

## 27. Backend feasibility 不属于 B5.5

B5.5 不验证：

- H3 是否支持某 movement
- 某 GPU 是否够显存
- concrete TTS 是否能精准到某时长
- ComfyUI workflow 是否能跑

```text
semantic valid ≠ backend executable
```

这些由 Asset Resolution / Execution Compilation / backend validation 负责。

## 28. Release profile compatibility

B5.5 验证 variant 是否满足它 pinned 的 ReleaseTargetProfile / SubtitleProfile / PlatformOverlayConstraintProfile 等。

Profile 本身是 input authority；B5.5 不联网动态替换成“今天最新平台规则”。

正式 finding 建议：

```text

  affected_planned_shot_ids[]
  affected_source_refs[]
  canonical_requirement_refs[]

  evidence

```

Resolution authority：

```text

B5_HUMAN_REVIEW

```

建议包含：

```text

```

`source_bundle_manifest` 列出所有 authoritative inputs 的 artifact_type/id/revision/hash。

## 31. Bundle hash / validator version

`validated_release_variant_bundle_hash` 必须基于 canonical serialization，不能依赖 file path、generated_at、machine-specific metadata 或随机 ordering。

Validator rule set 可以 versioned；同一 source bundle 在 validator contract 升级后可重新产生新 ValidationReport，但不得 silent 修改 source artifacts。

## 32. Qwen / Python

Python：

- id/revision/hash/approval lineage
- schema/enums
- completeness
- cross refs
- numeric timing bounds
- bundle hash
- forbidden boundary fields

Qwen：

- semantic equivalence diagnosis
- ambiguity / character voice assessment
- framing semantic assessment
- pacing assessment
- cross-modal semantic contradiction diagnosis

Qwen 只能诊断，不得 repair/select/self-approve。

## 33. Formal validation granularity

B5.5 formal validation 是：

```text
per episode
per ReleaseVariantIdentity
whole-bundle atomic validation
```

可以 incremental diagnostics，但正式 report 必须覆盖完整 Episode Release Variant bundle。

## 34. Change propagation

任何 authoritative source revision 改变：

```text
prior validated_release_variant_bundle_hash invalid
```

必须重新 B5.5。

旧 report 不得被拿来验证新 constituent revision。

## 35. 冻结原则

1. B5.5 是 B5 read-only integrated auditor。
2. 验证对象是 fully resolved exact bundle，禁止 implicit latest/default/current。
3. 正式输出 `ReleaseVariantValidationReport` 与 `validated_release_variant_bundle_hash`。
4. Result = FAIL / PASS_WITH_REVIEW_ITEMS / PASS；severity = BLOCKING / REVIEW_REQUIRED / WARNING。
5. Validator 不生成、选择、修改或修复 candidate。
6. Local PASS 不等于 integrated PASS。
7. Reveal/knowledge/ambiguity 必须跨 language/framing/subtitle/audio/timing 一起验证。
8. Localization 检查 semantic fidelity，不要求 literal equivalence。
9. PRIMARY PCR 必须在 release realization 后真正成立。
10. Required visibility/co-visibility 必须 perceptually meaningful。
11. B4.3 camera semantics 与 B4.4 continuity semantics 必须保持。
12. Numeric duration within range 不等于 timing semantics 自动合法。
13. Subtitle 不得提前/错误延迟 material reveal。
14. Audio bridge / segmentation realization 必须忠实继承 B4 contracts。
15. 必须检测 cross-B5 contradiction 与 unauthorized canonical change。
16. 每 finding 必须明确 resolution authority。
17. Backend feasibility 不属于 B5.5。
18. Canonical B5 artifact 不得泄漏 H3/ComfyUI/concrete asset/backend authority。
19. 任一 authoritative source revision change 都使 prior bundle hash 失效。
20. Formal validation per-episode/per-variant atomic。
21. PASS / PASS_WITH_REVIEW_ITEMS 才可进入 B5.6。
22. B5.5 PASS 不等于 EpisodeReleaseVariant APPROVED。
23. Qwen 可诊断；Python 负责 deterministic audit skeleton；Qwen 不能 repair/self-approve。
