# B7.3 — Release Timing / Dialogue / Audio Projection

状态：**FROZEN**

## 1. 职责

B7.3 将 B5.4 已批准的 release timing realization 精确投影到 B7.2 已确定的 ProductionShot semantic intervals。

核心：

```text
B4.5 = canonical timing / segmentation authority
B5.4 = release timing realization authority
B7.2 = ProductionShot temporal partition
B7.3 = timing/dialogue/audio projection authority
B7.6 = backend render/context realization
```

B7.3 是 projection layer，不是 localization/dialogue rewriting/backend timing improvisation layer。

## 2. 正式输入 / 输出

输入：

```text
ExecutionCompilationContext
EpisodeProductionShotSegmentationPlan
exact APPROVED EpisodeReleaseVariant / B5.4 timing realization
```

输出：

```text
EpisodeProductionShotTimingProjectionPlan
```

每个 ProductionShot 对应：

```text
ProductionShotTimingProjection
  production_shot_identity
  planned_shot_id
  semantic_release_window
  dialogue_projections[]
  subtitle_projections[]
  audio_event_projections[]
  audio_bridge_projections[]
  release_hold_projections[]
  boundary_constraints
  source_timing_refs[]
  provenance
  content_hash
```

## 3. 三套 timing 坐标

必须严格区分：

```text
canonical timing
release timing
ProductionShot-local timing
```

Projected event至少保留：

```text
source_release_window
projected_release_window
production_shot_local_window
```

Local time只是 derived coordinate，不是新的 timing authority。

## 4. Projection model

基本计算：

```text
release event ∩ ProductionShot semantic interval
→ event projection
```

典型 relation：

```text
FULLY_CONTAINED
STARTS_IN_SEGMENT
ENDS_IN_SEGMENT
CONTINUES_THROUGH_SEGMENT
```

B7可以 clip temporal interval，但不得创造新的 semantic event identity。

## 5. Event identity preservation

跨多个 ProductionShots 的一个 source event仍然只有一个 semantic identity。

例如一个 `Utterance U17` 跨两个 segments，可产生两个 projections，但不得变成两个独立 utterances。

原则：

```text
timing projection
≠ semantic event splitting
```

同样适用于 SubtitleCue、AudioEvent、ReleaseHold。

## 6. Dialogue / subtitle 分离

继续冻结：

```text
localized_spoken_text
≠ subtitle_text
```

因此 `DialogueProjection` 与 `SubtitleProjection` 独立，文字、timing、segmentation都不能互相推断。

DialogueProjection应引用 exact utterance / speaker / localized spoken-text refs，而不是重新写字符串。

## 7. Cross-segment dialogue

B7允许 clip一个 utterance的时间区间，但：

```text
B7 may clip a timing interval.
B7 may NOT invent a linguistic split.
```

禁止根据：

```text
60% duration → first 60% characters
```

猜 word/phrase boundary。

Cross-segment utterance只有以下合法实现路径：

1. B5 已有 timed phrase/word/subspan；
2. 整体 audio continuity可独立跨 video segments；
3. ExecutionProfile 明确支持 continuous realization/continuation。

否则：

```text
CROSS_SEGMENT_UTTERANCE_NOT_REALIZABLE
```

可尝试另一个 B4-authorized partition、另一个 ExecutionProfile，或 route B5/B4 revision。

## 8. B5 release-specific seam constraints

B4.5 决定潜在 semantic seam legality；B5.4 可以因 localized dialogue/reveal/audio semantics限制某个 seam 在具体 ReleaseVariant 中不可使用。

因此：

```text
B4 legal seam
≠ automatically usable seam for every ReleaseVariant
```

B5 可以 constrain existing seam，不可以创建新 seam。

若 B7.3 发现当前 B7.2 partition与 B5 timing冲突：

```text
invalidate segmentation
→ CompilationConstraintFeedback
→ rerun B7.2
```

不得在 B7.3 原地移动 boundary。

## 9. Subtitle projection

SubtitleCue独立于 spoken utterance。

跨 segment cue可投影到两段，但 source cue identity保持一个；不得造成 stitching 后 cue semantic duplication。

最重要：

```text
subtitle projection
≠ visual generation instruction
```

普通外挂字幕不应让 H3/ComfyUI 在画面底部生成文字。只有 scene 内真实存在且具有 semantic importance 的 in-world text 才属于 visual semantics/B6 asset requirement。

## 10. Subtitle reveal protection

B7.3 必须保留 B5 已批准 cue onset/end。

Local coordinate转换不得把：

```text
release cue 5.0–7.0
```

错误归一化为 segment-local `0.0–2.0`，如果 segment实际从 4.2 开始；正确 local onset为 0.8。

任何提前 reveal 都是 validation failure。

## 11. AudioSemanticEvent

B5.4 的 door slam、footstep、phone vibration、alarm、ambient transition、music sting 等都作为 semantic timing event投影。

Timing model必须支持：

```text
POINT
INTERVAL
```

不是所有 audio event都有 duration。

## 12. Boundary point event ownership

内部 segments使用 half-open ownership：

```text
[start, end)
```

最后一个 segment可使用 `[start, end]`。

因此 exact internal seam 上的 point event默认由 successor ProductionShot执行，避免重复 door slam / onset。

前一段可以拥有 boundary context，但：

```text
event execution ownership
≠ contextual visibility
```

## 13. AudioBridge

B5.4 audio bridge 是 release semantic object，例如 J-cut / L-cut / music carry。

正式区分：

```text
AudioBridge
≠ backend continuation overlap
```

Audio bridge可以跨 ProductionShots、甚至跨 PlannedShots，而不改变 ProductionShot ownership。

Backend previous-frame/latent continuation属于 B7.6 execution mechanics。

## 14. ReleaseHold

Approved release hold / reaction pause / intentional pause是 first-class semantic timing，不得为省 backend duration删除。

如果 backend不擅长精确实现 hold，可在 B7.6 使用合法 postprocess/frame-hold technique，但 approved timing不变。

## 15. SemanticWindow / RenderEnvelope / ContextEnvelope

B7.3 正式锁定：

```text
SemanticWindow
≠ RenderEnvelope
≠ ContextEnvelope
```

B7.3只拥有 SemanticWindow projection。

Backend固定 duration bucket、padding、trim、pre/post-roll、continuation overlap由 B7.6 实现，并不得反写 semantic timing。

## 16. Estimated vs measured audio

继续保持：

```text
estimated spoken duration
≠ measured audio duration
```

B7不能把 estimated timing提升成 measured evidence，也不能因 runtime waveform实际更长就自动改 B5 timeline。

如果 measured audio需要成为正式 release timing，应回 B5.4 revision，除非 B5已批准明确 tolerance/envelope。

## 17. Timing tolerance

只有 B5明确批准 duration tolerance/envelope时，B7才可在 envelope内选择具体 execution realization。

B7不得 invent tolerance、自动 speed-up或 truncate speech。

## 18. Asset boundary

B7.3知道：

```text
speaker = Linsey
voice continuity required
```

但不选择 `Linsey_voice_zh.wav` concrete asset。

具体 B6-approved voice/audio asset projection属于 B7.4。

## 19. Determinism / Qwen

相同 exact B5 timing + B7.2 segmentation + compiler policy应得到相同 projections、ownership、local timing和 hashes。

Normal B7.3 完全由 Python deterministic projection完成。

Qwen只能帮助解释为什么某 utterance/seam冲突以及应该 route哪个 upstream owner；不能自由切句、重写 localization或调整 reveal timing。

## 20. Failure categories

典型：

```text
TIMING_LINEAGE_MISMATCH
INVALID_RELEASE_TIME_WINDOW
EVENT_OUTSIDE_RELEASE_SHOT_WINDOW
BOUNDARY_TIMING_MAPPING_FAILURE
CROSS_SEGMENT_UTTERANCE_UNRESOLVED
UNSUPPORTED_LINGUISTIC_SPLIT_REQUIRED
SUBTITLE_REVEAL_VIOLATION
AUDIO_EVENT_OWNERSHIP_AMBIGUITY
AUDIO_BRIDGE_PROJECTION_FAILURE
RELEASE_HOLD_PROJECTION_FAILURE
NO_TIMING_COMPATIBLE_LEGAL_PARTITION
BACKEND_TIMING_REALIZATION_REQUIRED
```

## 21. 冻结原则

1. B7.3只投影 approved B5 timing，不 author/rewrite timing semantics。
2. canonical / release / ProductionShot-local timing严格分离。
3. local timing是 derived data，不是 authority。
4. source event identity跨 segment保持不变。
5. temporal clipping不等于 semantic splitting。
6. DialogueEvent与SubtitleCue严格分离。
7. B7不得按时间比例 invent linguistic split。
8. Cross-segment dialogue必须有正式 realization path。
9. B4.5创造 legal seam authority；B5只可限制具体 release 的 seam usability。
10. B7.3可 invalidate B7.2，但不得原地移动 seam。
11. Subtitle不得提前 reveal，普通字幕不得泄漏进 visual generation。
12. Boundary point event只有一个 execution owner。
13. Audio bridge不是 backend continuation。
14. Release hold不得被优化掉。
15. SemanticWindow / RenderEnvelope / ContextEnvelope严格分离。
16. Backend padding/trim/overlap不得重写 B4/B5 timing。
17. Estimated/measured audio evidence不混淆。
18. B7.3不选择 concrete assets。
19. Normal projection deterministic，不依赖 Qwen。
