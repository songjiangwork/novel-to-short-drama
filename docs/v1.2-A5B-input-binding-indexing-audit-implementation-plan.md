## 12. Deterministic source_order_key

A5A field 是 string。

A5B 使用：

```text
{chunk_ordinal:06d}:{paragraph_ordinal:09d}:{category_ordinal:02d}:{candidate_suffix:09d}:{candidate_ref}
```

其中：

```text
chunk_ordinal
= position in exact ChunkManifest.chunk_refs, starting 1

paragraph_ordinal
= earliest PRIMARY EvidenceRef paragraph position in exact SourceDocument, starting 1

category_ordinal:
  fact         = 1
  event        = 2
  relationship = 3

candidate_suffix
= numeric suffix of local candidate id
```

如果没有 primary evidence：

```text
fallback = earliest evidence paragraph position
```

如果 candidate 没有任何 evidence，A3 应已拒绝；若仍出现，fail closed。

Evidence paragraph 不存在于 exact SourceDocument：

```text
FAIL CLOSED
```

同一 source key tie 最终由完整 candidate ref deterministic break。
