# 3. Fact semantic decision domain

Provider decision enum EXACT：

```text
same_fact
compatible_fact
state_change
conflict
unrelated
uncertain
```

语义：

## same_fact

同一个事实的重复或等价表达。

后续只有该 decision 可以形成 fact identity merge edge。

## compatible_fact

两个事实可以同时成立，但不是同一个事实。

不得 merge。

## state_change

同一语义状态在不同 narrative/source point 发生真实变化。

不得 merge；后续 A5E 可建立 StateTransition。

## conflict

两个 source-backed claims 在其上下文中不可同时成立，并且 evidence 不足以解释为正常 state change。

不得 merge；后续 A5E 可建立 StoryConflict。

## unrelated

不是同一事实语义问题。

不得 merge；无 semantic graph edge。

## uncertain

pair-local evidence 无法支持可靠分类。

```text
uncertain = successful semantic result
```

不得因为 uncertain 再 retry 逼模型选边。

选择 P2 的 rationale（precision / reliability-first v1）：

```text
P1:
safe but requires 353 provider blocks.

P2:
cuts provider round trips approximately in half versus P1,
while requiring at most 12 structured decisions per response.

P3:
cuts calls further, but doubles the per-response decision count to 24
and materially increases structured-output completeness risk under the
tracked consolidation-llm-v1 max_output_tokens = 4096.
```

P3 并非被认定不可行；它只是在没有证据表明更大的 response surface
值得额外 structured-output 风险时，未作为 v1 被选择。

冻结的 canonical material 是**行为化 limits**（12 / 24），不是 policy label。
A5C-B 可构造 `FactSemanticPackingPolicy("fact-semantic-packing-v1", 12, 24)`，
其 block / request identity 与 audited P2 完全一致（name 不进入 identity material）。

**provider smoke 不选择 packing policy：** 权威链为 Alice zero-provider audit →
architecture review → `fact-semantic-packing-v1` FROZEN at 12 / 24。未来的
provider smoke 只**验证**冻结策略的实现，不动态选择 P1 / P2 / P3；若实跑证明
12 / 24 structurally unsuitable，必须走 explicit refinement / policy version
change，不得在 runtime 静默调整 block size。

A5C-B 现在可开始（本文件状态：FROZEN — A5C-A POST-AUDIT / A5C-B READY），
