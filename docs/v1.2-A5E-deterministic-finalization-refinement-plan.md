## 2. Frozen v1 principles

1. 只有 same_fact / same_event / same_relationship 建立 identity merge edge。
2. connected-component transitivity 由 Python authoritative。
3. explicit hard-negative 与 same-component identity 冲突时 fail closed。
4. uncertain 是 non-edge、non-veto：不建立 edge，也不作为 hard-negative contradiction。
5. canonical semantic payload 不做新的 LLM synthesis。
6. 每个 component 的 earliest member 是 representative。
7. candidate refs / evidence refs 保留 component provenance。
8. canonical IDs 由 deterministic source order 分配。
9. narrative/source order 不等于 chronology。
10. relationship identity 与 relationship state history 分离。
11. relationship state 变化在 v1 只进入 CanonicalRelationship.state_history。
12. v1 不 emit relationship StateTransition。
13. v1 不 emit relationship_state_conflict。
14. Fact state_change 产生 StateTransition。
15. Fact conflict 产生 StoryConflict(kind=fact_conflict)。
16. Event different_event 永远不产生 StoryConflict。
17. structural contradiction 必须 FAIL CLOSED；小说自身 source conflict 是 legal PASS content。

## 3. Authoritative order

所有 candidate 的唯一 member order：

~~~text
(source_order_key, global_candidate_ref)
~~~

ascending。

component key = component earliest member 的同一 tuple。

components 按 component key ascending 排序。

禁止使用 set iteration、decision arrival order、provider response order、dict incidental order 或 canonical ID 本身作为 source authority。

---

## 4. Stable canonical IDs

每个 domain 独立按 component order 1-based 分配：

~~~text
fact_000001...
evt_000001...
rel_000001...
~~~

最少 6 位数字。

ID 不依赖 provider/model、decision hash、unordered traversal、revision 或 timestamp。

---

## 5. Exact EvidenceRef aggregation

Exact EvidenceRef identity 继续是：

~~~text
(paragraph_id, role, strength, excerpt)
~~~

aggregation：

1. member 按 authoritative member order；
2. member 内保持原始 evidence_refs 顺序；
3. exact identity stable dedupe；
4. first occurrence wins；
5. excerpt 不 normalize；
6. excerpt=None 与任意字符串不同。

适用于 CanonicalFact、CanonicalEvent、RelationshipState，以及本文件指定的 side objects。

## 6. Identity graphs

三个 domain 独立建 undirected graph。

Node universe 必须完整等于 planning_result.index 中该 domain candidate universe；singleton 也必须成为 component。

Edges only：

~~~text
Fact          same_fact
Event         same_event
Relationship  same_relationship
~~~

推荐 union-find / DSU，但内部算法不是 persisted contract。

## 7. Graph contradictions

### Fact hard-negative

以下 explicit decisions 是 hard-negative identity assertion：

~~~text
compatible_fact
state_change
conflict
unrelated
~~~

如果 endpoints 最终位于同一 same_fact component：FAIL CLOSED。

uncertain 不是 hard-negative。例如：

~~~text
A same_fact B
B same_fact C
A uncertain C
~~~

component {A,B,C} 合法。

### Event

different_event endpoints 位于同一 same_event component：FAIL CLOSED。

uncertain 是 non-edge、non-veto。

### Relationship

different_relationship endpoints 位于同一 same_relationship component：FAIL CLOSED。

uncertain 是 non-edge、non-veto。

这些 contradiction 都是 structural inconsistency，不得转换为 StoryConflict。

每个 component：

representative = earliest member
~~~

除本文明确指定的 aggregation 字段外，canonical semantic payload 取 representative。

v1 禁止 field voting、majority semantics、summary synthesis、文本拼接或额外 provider pass。

## 9. Canonical Fact v1

每个 same_fact component → one CanonicalFact。

字段：

~~~text
fact_id
  stable canonical ID

fact_type
  representative.fact_type

statement_zh
  representative.statement_zh

subject_refs
  representative.subject_refs

object_refs
  representative.object_refs

candidate_fact_refs
  all member refs in authoritative member order

evidence_refs
  stable exact union of all member evidence

first_source_order
  representative.source_order_key

continuity_relevant
  true iff ANY member.fact_type == continuity_relevant
~~~

v1 不根据 statement text、generic state_change 或 production assumptions 推断 continuity_relevant。

---

## 10. Fact StateTransition v1

只有 explicit Fact decision state_change 产生 StateTransition。

如果 decision endpoints 映射到同一个 canonical fact：FAIL CLOSED。

Direction 只使用 component source order：

~~~text
earlier canonical fact → later canonical fact
~~~

禁止把 provider left/right 当 temporal direction，也不从文本猜 chronology。

每一个 state_change decision 产生一个 transition；v1 不合并多个 decision。

字段：

~~~text
from_fact_id
  earlier canonical fact

to_fact_id
  later canonical fact

subject_refs
  stable exact intersection of from_fact.subject_refs
  and to_fact.subject_refs
  preserving from_fact order

transition_kind
  state_change

source_decision_ref
  decision_id

evidence_refs
  exact decision.evidence_refs

narrative_order
  numeric ordinal of to_fact_id
~~~

例如 fact_000017 → narrative_order 17。

Transitions 按：

~~~text
(to_fact ordinal, from_fact ordinal, source_decision_ref)
~~~

ascending 后分配 trans_000001...。

---

## 11. Fact StoryConflict v1

只有 explicit Fact decision conflict 产生 StoryConflict。

如果 endpoints 映射到同一 canonical fact：FAIL CLOSED。

v1 每个 conflict decision 产生一个独立 StoryConflict，不做 conflict aggregation。

字段：

~~~text
conflict_kind
  fact_conflict

fact_ids
  earlier fact id, later fact id

relationship_ids
  empty

candidate_refs
  exact decision endpoint candidate refs

decision_refs
  exact decision_id only

evidence_refs
  exact decision.evidence_refs

status
  unresolved
~~~

Conflicts 按：

~~~text
(later fact ordinal, earlier fact ordinal, decision_id)
~~~

ascending 后分配 conf_000001...。

A5E v1 只 emit fact_conflict。

compatible_fact / unrelated / uncertain 不创建 side object。

## 12. Canonical Event v1

每个 same_event component → one CanonicalEvent。

字段：

~~~text
event_id
  stable canonical ID

narrative_order
  canonical event component ordinal, 1-based

summary_zh
  representative.summary_zh

participants
  representative.participants

locations
  representative.locations

candidate_event_refs
  all member refs in authoritative member order

evidence_refs
  stable exact union

first_source_order
  representative.source_order_key
~~~

v1 不 union participants/locations。same_event 建立 identity equivalence，但不授权 Python 合成更宽 semantic payload。

### temporal_mode

这是唯一 component-level conservative Event semantic aggregation：

- 所有 mode 相同 → 该 mode。
- 一个 non-unknown known mode + 任意 unknown → known mode。
- 两个或以上不同 known modes → unknown。

例如：

~~~text
unknown, memory, unknown → memory
normal, memory          → unknown
flashback, dream       → unknown
~~~

不 fail identity，不猜 chronology。

different_event 只表示 not-same；永远不产生 StoryConflict。

## 13. Canonical Relationship v1

每个 same_relationship component → one CanonicalRelationship。

### Direction-aware endpoint signature

每个 candidate 形成：

~~~text
directed:
  (directed, source, target)

symmetric:
  (symmetric, min(source,target), max(source,target))

unknown:
  (unknown, source, target)
~~~

unknown 保持 ordered，不按 symmetric 处理。

同一 component 所有 signature 必须完全相同，否则 FAIL CLOSED。

字段：

~~~text
relationship_id
  stable canonical ID

source_entity_ref / target_entity_ref / direction
  from shared component signature

relationship_type_zh
  representative.relationship_type_zh

candidate_relationship_refs
  all member refs in authoritative member order

first_source_order
  representative.source_order_key
~~~

symmetric 的 canonical endpoints 使用 min/max；directed / unknown 保持 ordered。

## 14. Relationship state_history v1

Relationship identity 与 state 完全分离。

state_zh=None 的 candidate 不产生 RelationshipState，但仍必须保留在 parent candidate_relationship_refs。

只取 state_zh != None 的 members，保持 authoritative member order，形成 observed state sequence。

只对 observed sequence 中连续且 exact-equal 的 state_zh 分组。

~~~text
戒备, 戒备, 信任, 信任, 戒备
→ 戒备 / 信任 / 戒备
~~~

None 不构成 state，也不主动制造 state boundary：

~~~text
戒备, None, 戒备
→ observed sequence: 戒备, 戒备
→ one state item
~~~

每个 RelationshipState：

~~~text
state_zh
  exact grouped string

candidate_relationship_refs
  exact group members in source order

evidence_refs
  stable exact union of group evidence

narrative_order
  1-based source rank of first group member
  within COMPLETE indexed RelationshipCandidate universe
~~~

Relationship candidate source-rank：

~~~text
sort all planning_result.index.relationships by
(source_order_key, global_candidate_ref)
then assign 1..N
~~~

## 15. Relationship StateTransition / StoryConflict v1

现有 A5A StateTransition 是 fact-addressed：

~~~text
from_fact_id
to_fact_id
subject_refs
~~~

虽然 STATE_TRANSITION_KINDS 预留 relationship_state_change，但 A5E v1：

~~~text
DO NOT change StateTransition schema
DO NOT emit relationship StateTransition
~~~

Relationship 状态变化 authoritative representation 只有 CanonicalRelationship.state_history。

relationship_state_change 在 v1 是 reserved / not emitted。

同理，Relationship semantic classifier 没有 relationship_state_conflict decision。不同 state_zh 是 state_history，不自动成为 conflict。

~~~text
different state_zh
→ state_history

different_relationship inside same component
→ structural FAIL CLOSED

uncertain
→ non-edge / non-veto
~~~

relationship_state_conflict 在 v1 是 reserved / not emitted。

Pi 不得把 relationship_id 塞进 from_fact_id/to_fact_id，也不得仅凭不同 state_zh 创造 StoryConflict。

## 17. Cross-artifact validation

### StateTransition
- from_fact_id / to_fact_id 都存在；
- 两者不同；
- source_decision_ref resolve 到 Fact semantic decision；
- source decision == state_change。

### StoryConflict
- fact_ids 全部存在；
- relationship_ids == empty；
- candidate_refs 都是 Fact candidates；
- decision_refs resolve 到 Fact conflict decision；
- status == unresolved。

### RelationshipState
- refs 都属于 parent relationship component；
- state_zh exact-match contributing candidates；
- evidence exact-derived；
- narrative_order > 0。

每个 canonical object / RelationshipState / side object 内不得有 duplicate exact EvidenceRef identity。

不同 canonical objects 之间可以合法共享相同 EvidenceRef，不做 global ownership 假设。
