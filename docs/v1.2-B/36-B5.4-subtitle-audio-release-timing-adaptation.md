# B5.4 — Subtitle / Audio / Release Timing Adaptation

状态：**FROZEN**

## 1. 职责

B5.4 把 localized spoken realization、subtitle presentation、audio semantic continuity 与 release-specific timing 组织到 B4.4/B4.5 已批准的 canonical transition/timing envelope 内。

正式输出：

```text
EpisodeReleaseTimingPlan
```

并包含：

```text
SubtitleRealizationPlan
AudioRealizationPlan
ReleaseShotTimingSpecification
```

B5.4 仍然是 semantic release planning，不是 concrete audio/render timeline compilation。

## 2. 核心边界

B4.5 是 canonical editorial timing authority：

```text
ShotTimingSpecification
GenerationSegmentationContract
ShotTimingAnchor
```

B5.4 只负责：

```text
release-specific timing realization
inside that approved envelope
```

正式原则：

```text
Release timing may realize, compress, expand,
align and synchronize within the approved timing envelope,
but may not redefine canonical editorial timing obligations.
```

## 3. 正式输入

B5.4 exact consume：

```text
EpisodeReleaseVariantContext
EpisodeDialogueLocalizationPlan
EpisodeReleaseFramingPlan
EpisodeShotPlan
```

所有 refs 必须 id/revision/hash exact match；禁止 independent latest resolution。

## 4. EpisodeReleaseTimingPlan

建议包含：

```text
release_timing_plan_id
revision
content_hash
source_release_variant_context_ref
source_episode_shot_plan_ref
source_dialogue_localization_plan_ref
source_release_framing_plan_ref
subtitle_realization_plan
audio_realization_plan
shot_timing_specifications[]
release_timing_conflicts[]
review_items[]
```

每个 PlannedShot exact 对应：

```text
ReleaseShotTimingSpecification
```

## 5. ReleaseShotTimingSpecification

概念结构：

```text
ReleaseShotTimingSpecification
{
  planned_shot_id
  canonical_timing_ref
  target_release_duration
  acceptable_release_duration_range
  timing_anchor_realizations[]
  spoken_timing_bindings[]
  subtitle_timing_bindings[]
  audio_event_bindings[]
  hold_adjustments[]
  transition_timing_realization
  segmentation_realization_constraints
  preservation_status
  review_flags
}
```

B5.4 不创建新的 editorial Shot identity。

## 6. Canonical duration 与 release duration

B4 `target/min/max/acceptable range` 是 canonical timing contract。

B5.4 可以选择 release-specific target realization，但不得改写 B4 canonical range。

不同语言可以有不同 release duration，只要仍保持：

- canonical duration constraints
- timing-anchor relationships
- pacing semantic function
- reveal timing
- reaction/action obligations

## 7. TimingAnchorRealization

B5.4 将 B4.5 `ShotTimingAnchor` 映射为 release-specific `TimingAnchorRealization`。

必须保持 canonical relations：

```text
BEFORE
AT_START
DURING
AT_COMPLETION
AFTER
```

例如 canonical `reaction AFTER dialogue completion` 不能因英文更长而改成 `reaction DURING dialogue`，除非 canonical contract 本身允许 overlap。

## 8. Spoken text 与 subtitle text

正式保持：

```text
localized_spoken_text ≠ subtitle_text
```

B5.2 定义 spoken localization；B5.4 正式创建：

```text
SubtitleCue
```

允许：

```text
1 LocalizedUtterance → 1..N SubtitleCues
```

也可在语义/时序兼容时将多个短 utterances 合并为 cue。

## 9. SubtitleCue

建议包含：

```text
subtitle_cue_id
source_localized_utterance_refs[]
subtitle_text
semantic_content_refs[]
display_timing_intent
reading_constraints
line_break_intent
speaker_context
overlap_policy
review_flags
```

B5.4 不绑定最终 ASS/SRT line number、font file、pixel x/y、font size。

## 10. Subtitle semantic compression

Subtitle 可以为 readability 做：

- remove semantically empty filler
- reduce non-essential repetition
- simplify spoken syntax
- split/merge cues

但不得：

- 删除 required information
- 删除/提前 reveal
- 改变 denial/question/command 等 speech act
- 改变 character intent
- 消除 canonical ambiguity

```text
subtitle compression ≠ free summarization
```

## 11. SubtitleReadingConstraint

正式支持 release/profile-specific reading constraints，例如：

```text
MAX_LINES
MAX_SEMANTIC_DENSITY
MIN_READABILITY_HOLD
AVOID_ORPHAN_FRAGMENT
AVOID_SEMANTICALLY_BAD_BREAK
```

具体阅读速度目标由 pinned SubtitleProfile 提供，不作为 universal canonical constant。

## 12. Subtitle reveal safety

Subtitle 不得比 canonical spoken/visual reveal 更早泄露 audience knowledge。

正式支持：

```text
SubtitleRevealConstraint
```

如果 spoken line 在 pause 后才 reveal identity，不能一开始就显示完整 reveal subtitle。

```text
early subtitle reveal = BLOCKING
```

Cue merge 也不得跨 canonical reveal boundary 提前显示后续信息。

## 13. Subtitle timing 与 waveform timing 分离

Subtitle 可以略早出现/略晚消失/跨自然 spoken pause 持续，只要：

- 不提前 reveal
- 不造成语义 chronology inversion
- 不破坏 speaker/scene interpretation

因此：

```text
subtitle cue timing ≠ exact waveform timing
```

## 14. Subtitle safe area 与 framing

B5.3 提供 subtitle-safe framing intent；B5.4 提供具体 semantic cue realization。

局部 conflict resolution 优先顺序：

```text
subtitle wording refinement
→ cue split/merge
→ cue timing refinement
→ subtitle-zone refinement
→ B5.3 framing refinement
→ canonical conflict 才升级 B4
```

## 15. AudioRealizationPlan

B5.4 的 AudioRealizationPlan 只描述：

```text
which semantic audio event occurs
when
with what role
with what overlap/continuity relationship
```

不描述 concrete WAV/TTS model/path。

## 16. AudioSemanticEvent

可支持：

```text
SPOKEN_UTTERANCE
NARRATION
VOICE_OVER
OFFSCREEN_SPEECH
AMBIENT_AUDIO
SOUND_EFFECT
MUSIC_CUE
```

但 B5.4 不能自行创作 upstream 未授权的 narrative sound design。Ambient/SFX/Music 只有在已有 semantic authority 或 release timing contract 确实需要时才进入。

建议结构：

```text
AudioSemanticEvent
{
  audio_event_id
  source_semantic_ref
  event_type
  speaker_or_source_ref
  content_or_intent_ref
  timing_relation
  overlap_relation
  continuity_role
  localization_status
}
```

## 17. Estimated vs measured audio duration

B5.2 的：

```text
estimated_spoken_duration
```

只是 planning signal。

```text
estimated_spoken_duration ≠ measured_audio_duration
```

Measured duration 只有 concrete audio asset 出现后才能确认，应属于后续 Asset Resolution / Execution Compilation validation。

B5.4 可以定义 `AudioTimingTolerance`：preferred duration、acceptable range、must-complete-before、allowed overlap 等，以供 downstream deterministic check。

## 18. Audio overlap / bridge

B5.4 必须 faithful realize B4.4 audio bridge semantics，包括：

```text
PREVIOUS_AUDIO_CONTINUES
NEXT_AUDIO_PRELAPS
```

不重新引入 J-cut / L-cut 作为 canonical taxonomy，也不自行“为了更酷”添加 bridge。

如果 B4 要求 bridge，B5.4 不能因 localization 更长就 silent 删除。

## 19. ReleaseHoldAdjustment

B5.4 可以在 B4 timing envelope 内定义：

```text
REACTION_HOLD
READABILITY_HOLD
BREATHING_HOLD
TRANSITION_HOLD
```

但不得改变 semantic phase ordering、reveal placement、timing anchors 或 pacing function。

数字仍在 max range 内也不代表一定合法；例如 `ABRUPT` interruption 被加成长停顿仍可能 semantic invalid。

## 20. Timing semantic function

Release realization 必须保留 canonical pacing function，例如：

```text
ABRUPT
LINGERING
RAPID
SUSPENSE_HOLD
REACTION_BEAT
INTERRUPTED
CONTINUOUS_ACTION
```

该集合可作为 semantic vocabulary 扩展，不要求一次性穷举。

## 21. Speech-rate adaptation

B5.4 可以保存 semantic speech-rate intent：

```text
NORMAL
BRISK
SLOW
URGENT
DELIBERATE
```

不能直接保存 backend TTS speed parameter。

Speech-rate intent 必须符合 CharacterVoiceConstraint / PerformanceMarker / ShotTimingSpecification。

## 22. Transition timing

B4.4 transition type 是 canonical：

```text
CUT
MATCH_ON_ACTION
JUMP_CUT
DISSOLVE
FADE
OTHER_SEMANTIC
```

B5.4 可以做 release-specific transition timing realization，但不能把 CUT 改成 DISSOLVE 或为字幕增加 hidden fade/freeze。

`MATCH_ON_ACTION` 必须保持 action-phase alignment；无法兼容时产生 explicit timing conflict。

## 23. Generation segmentation

B5.4 可以根据 target language/release timing refine：

```text
ReleaseSegmentationRealizationConstraint
```

例如 safe seam candidate / forbidden region 的 release-relative位置。

但必须忠实继承 B4：

```text
SINGLE_PREFERRED
SPLIT_ALLOWED
SPLIT_DISCOURAGED
SPLIT_FORBIDDEN
```

B5.4 不能把 SPLIT_FORBIDDEN 改成 SPLIT_ALLOWED。

Generation seam 不得产生观众可见 editorial cut；如果技术要求 visible cut，必须回 B4.2。

## 24. Conflict taxonomy

至少支持：

```text
SPOKEN_DURATION_EXCEEDS_ENVELOPE
SPOKEN_DURATION_BELOW_REQUIRED_HOLD
SUBTITLE_READABILITY_CONFLICT
SUBTITLE_REVEAL_CONFLICT
SUBTITLE_SAFE_AREA_TIMING_CONFLICT
AUDIO_OVERLAP_CONFLICT
AUDIO_BRIDGE_CONFLICT
TIMING_ANCHOR_VIOLATION
REACTION_HOLD_CONFLICT
PACING_FUNCTION_VIOLATION
MATCH_ON_ACTION_TIMING_CONFLICT
TRANSITION_TIMING_CONFLICT
SEGMENTATION_SEAM_CONFLICT
```

## 25. Resolution authority

每个 conflict 必须明确：

```text
B5_2_LOCALIZATION_REFINEMENT
B5_3_FRAMING_REFINEMENT
B5_4_TIMING_REFINEMENT
B5_REVIEW
REQUIRES_B4_REVISION
REQUIRES_UPSTREAM_REVISION
```

典型 spoken-duration escalation：

```text
B5.2 wording refinement
→ B5.4 legal timing/hold refinement
→ still impossible
→ REQUIRES_B4_REVISION
```

## 26. Local validation

B5.4 local validation 至少检查：

- exact source refs
- all PlannedShots covered
- all localized spoken utterances accounted for
- subtitle semantic completeness
- subtitle reveal safety
- timing-anchor compatibility
- spoken-duration compatibility
- audio overlap/bridge compatibility
- framing/subtitle compatibility
- pacing semantic preservation
- segmentation-contract compatibility
- transition timing compatibility

Severity：BLOCKING / REVIEW_REQUIRED / WARNING。

Validator 不 silent auto-fix。

## 27. Concrete file / timeline boundary

```text
EpisodeReleaseTimingPlan
≠ final EDL
≠ audio waveform timeline
≠ concrete SRT/ASS file
```

B5.4 是 release-specific semantic timing authority。

后续 Execution Compilation 才可 materialize concrete SRT/ASS、audio timeline、ProductionShot durations、backend clip timing。

## 28. PlannedShot / ProductionShot boundary

B5.4 仍在 PlannedShot level。

```text
ReleaseShotTimingSpecification
= PlannedShot-level release timing authority

ProductionShot
= downstream execution segment realization
```

若一个 PlannedShot 后来编译为多个 ProductionShots，其总和必须实现同一个 ReleaseShotTimingSpecification。

## 29. Qwen / Python

Qwen：

- subtitle compression/segmentation reasoning
- pacing judgment
- audio-overlap reasoning
- timing conflict diagnosis

Python：

- exact refs
- timing numeric constraints
- schema/state/hash
- deterministic selected candidate recording
- local validation skeleton

Qwen 不得扩大 B4 duration envelope、改变 transition type、移动 reveal、创建 editorial cut 或 self-approve。

## 30. 冻结原则

1. B4.5 是 canonical editorial timing authority。
2. B5.4 输出 `EpisodeReleaseTimingPlan`，每 PlannedShot exact 一个 selected `ReleaseShotTimingSpecification`。
3. B5.4 只在 B4 timing envelope 内做 release-specific timing realization。
4. localized spoken text 与 subtitle text 分离。
5. SubtitleCue 可 split/merge linguistic content，但不能改变 canonical semantics/reveal timing。
6. Subtitle 不得提前泄露 audience knowledge。
7. estimated_spoken_duration 不等于 measured_audio_duration。
8. AudioRealizationPlan 保持 asset-unresolved。
9. audio bridge 必须忠实实现 B4.4 semantics。
10. release hold adjustment 不得改变 pacing semantic function。
11. transition type 不得 silent 修改。
12. generation seam 不得变成 hidden editorial cut。
13. Conflict 必须有明确 resolution authority。
14. wording conflict 优先 B5.2；framing conflict优先 B5.3；canonical timing conflict 回 B4。
15. EpisodeReleaseTimingPlan 不等于最终 SRT/ASS、waveform timeline 或 EDL。
16. Qwen 做 semantic reasoning；Python 做 refs/state/hash/validation。
17. B5.4 保持 backend-agnostic，不绑定具体 TTS/H3/ComfyUI/audio file。
