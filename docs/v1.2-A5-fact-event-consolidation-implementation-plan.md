
# 5. Reference Binding Layer

A5 的第一项正式能力不是 dedupe，而是 **reference binding**。

每个 A3 local entity ref：

```text
cand_char_001
```

先结合所属 chunk：

```text
CH005_C001:cand_char_001
```

再通过 exact A4 EntityMapEntry 转换为：

```text
char_XXXX
loc_XXXX
unres_XXXX
```

例如：

```text
CH005_C001:cand_char_001
→ char_0007
```

或：

```text
CH005_C001:cand_unres_002
→ unres_0013
```

## 5.1 Binding invariants

必须满足：

1. 每个 A3 entity ref 都能形成合法 global candidate ref。
2. 每个 global candidate ref 在 exact EntityMap 中恰好出现一次。
3. resolved entry 必须绑定 canonical_id。
4. unresolved entry 必须绑定 unresolved_id。
5. 不允许 silently drop unresolved identity。
6. 不允许 A5 猜测 unresolved identity。
7. 不允许 A5 根据 name/summary 绕过 A4 EntityMap 自行重新 reconcile。
8. binding 后类型必须与 A3 field restriction 相容。
9. duplicate bound refs 在 canonicalization 时按字段 contract deterministic 去重。
10. binding failure 是 structural failure，不进入 provider retry。

# 9. Fact pair semantics

Frozen semantic classification：

```text
same_fact
compatible_fact
state_change
conflict
unrelated
uncertain
```

语义必须固定：

## same_fact

同一个事实的重复表达。

```text
→ 可以形成 fact merge edge
```

## compatible_fact

两个事实可以同时成立，但不是同一个事实。

```text
→ 不 merge
→ 两个 canonical facts 都保留
→ 可保留 compatibility decision provenance
```

## state_change

同一个 subject/domain 在不同 narrative point 发生状态变化。

例如：

```text
Alice has the key
→
Alice loses the key
```

```text
→ 不 merge
→ 两个 canonical facts 都保留
→ 建立 StateTransition
```

## conflict

两个 source-backed claims 在其语义上下文中不可同时成立，且没有足够 evidence 支持把差异解释为正常 state change。

```text
→ 不 merge
→ 两个 canonical facts 都保留
→ 建立 StoryConflict
```

## unrelated

```text
→ 不 merge
→ 无 semantic edge
```

## uncertain

```text
→ 不 merge
→ 显式保留 uncertainty
→ semantic uncertainty 是成功结果
```

禁止：

```text
compatible_fact → merge
state_change    → overwrite earlier state
conflict        → last-write-wins
uncertain       → retry until model picks a side
```


5. audit 不调用 provider。
6. audit 输出 candidate universe / pair universe / signal distribution。
7. 具体 blocking-v1 规则在 audit 后冻结。
8. 不允许 broad stopword / fuzzy heuristics 在没有数据证明前进入 v1。
9. precision-first。
10. semantic pair volume 必须可解释、可复现。

- pair order deterministic；

```text
→ try_reuse_current()
```

exact hit：

```text

→ reused = true
→ 0 provider calls
```

miss：

```text

→ deterministic finalization
→ validation
→ upstream stability check
→ immutable publication
→ CAS CURRENT
→ reused = false
```

只允许 current-only reuse。

初版不扫描 historical revisions 去 resurrect old semantic identity。

# 48. Frozen decisions summary

以下现在冻结：

1. A5 只消费 coherent current A4 snapshot 及其 exact pinned A3 inputs。
2. Reference binding precedes dedupe/blocking。
3. unresolved identity 必须保留，不允许 A5 猜测。
4. Fact/Event/Relationship 是三个独立 consolidation domains。
5. only same_fact / same_event / same_relationship create identity merge edges。
6. compatible/state_change/conflict/unrelated/uncertain 均不直接 merge fact identity。
7. conflict 显式持久化，禁止 last-write-wins。
8. Event different_event 不等于 StoryConflict。
9. Relationship identity 与 state history 分离。
10. narrative order deterministic；chronology 不确定时不猜。
11. semantic provider 使用 pair-local evidence selectors。
12. exact EvidenceRef stable dedupe 继续沿用 A4 invariant。
13. canonical IDs 全部由 Python deterministic 分配。
14. semantic uncertainty 是成功结果，不为追求确定性 retry。
15. A5 root authority 是 ConsolidationManifest。
16. A5 reuse 在 provider call 前判定。
17. A5 semantic identity backend-neutral。
18. current-only exact reuse；初版不 resurrection historical revision。
19. fresh publish 前必须 re-check upstream stability。
20. A5B blocking-v1 必须经过 Alice zero-provider audit 后冻结。
21. A5G fresh + exact rerun 是完成 gate。
22. A5A–A5G 顺序实施，小 PR，Draft PR，用户自行 merge。
