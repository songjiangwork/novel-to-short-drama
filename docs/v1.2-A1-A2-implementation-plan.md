## 4. A1 canonical SourceDocument contract

Canonical artifact type：

```text
source_document
```

MVP 默认单源 logical document id：

```text
src_001
```

Artifact ID：

```text
<project_id>.src_001
```

Revision 是单调递增 integer；不得从 timestamp、path 或文件名推导。

### Payload

建议固定为：

```json
{
  "schema_version": 1,
  "project_id": "my-project",
  "document_id": "src_001",
  "source": {
    "type": "txt",
    "path": "source/novel.txt",
    "raw_sha256": "...",
    "byte_size": 123456,
    "declared_language": "zh-CN",
    "detected_language": "zh",
    "language_detector": "langid-1.1.6"
  },
  "normalization": {
    "input_encoding": "utf-8",
    "newline": "LF",
    "parser_id": "short_drama_source_ingestion_v1",
    "parser_version": "1"
  },
  "structure": {
    "chapters": [
      {
        "chapter_id": "CH001",
        "title_original": "第一章",
        "heading_kind": "chapter",
        "paragraphs": [
          {
            "paragraph_id": "CH001_P0001",
            "text_original": "...",
            "source_pages": null
          }
        ]
      }
    ]
  }
}
```

PDF paragraph 的 `source_pages` 是 1-based page integer array；TXT 为 `null`。

### Important identity rules

`source.path` 保存 project source 配置中原始、可重现的 path string，不把机器相关 absolute resolved path 放进 canonical payload。

文件系统实际读取路径：

```text
project.yaml parent directory
+
project.source.path
```

Raw source identity 由：

```text
raw_sha256 = SHA256(original source bytes)
```

提供。

同一 raw file 在不同机器路径下，只要 project source path、解析器版本和输出结构相同，SourceDocument canonical content 不应因 absolute path 不同而变化。

## 5. TXT decoding / normalization

A1 必须 deterministic、fail closed。

默认 decoding policy：

1. UTF-8 BOM → `utf-8-sig`；
2. UTF-16 / UTF-32 BOM → 对应 BOM-aware decoder；
3. 无 BOM → strict UTF-8；
4. 非上述文本必须由 CLI `--encoding` 显式指定；
5. 不做 silent lossy replacement (`errors=replace` 禁止)。

Normalization：

```text
CRLF / CR → LF
```

不做：

- 全文翻译；
- Unicode semantic rewriting；
- smart quotes replacement；
- destructive punctuation normalization；
- spell correction。

Raw bytes hash 始终保留，因此 normalization 不替代原文件 evidence。

## 6. PDF extraction contract

新增 lightweight PDF dependency：

```text
pypdf
```

仅支持 text-based PDF。

要求：

- 逐页调用 text extraction；
- page number 作为辅助 provenance；
- 不做 OCR；
- 不猜图像中文字；
- 不自动删除 header/footer；
- 不跨页 heuristic 拼接“可能是同一段”的段落；
- 空白页允许；
- 整个 PDF 无可用文本时 fail closed，并明确提示 OCR 不在 MVP。

PDF parser/version 必须记录在 normalization metadata，使未来 parser 行为变化能够产生新的 immutable SourceDocument revision，而不是静默解释为旧 artifact。

## 8. Deterministic chapter detection

Chapter detector 必须 purely Python / regex，不调用 LLM。

至少支持 anchored full-line forms：

```text
Chapter 1
Chapter One
Part II
Prologue
Epilogue
第一章
第十二章
第一卷
序章
楔子
尾声
```

Heading line：

- 保存到 `title_original`；
- 不同时作为普通 paragraph 重复保存。

内部 ID 不复制原章节数字；按实际 source order deterministic 生成：

```text
CH001
CH002
...
```

如果不存在可靠 heading：

```text
CH001
heading_kind = synthetic
```

如果第一条真实 heading 之前存在正文，则该 preface material 进入一个 synthetic chapter，再继续后续 chapter IDs。

### Paragraph split

先切 chapter，再切 paragraph。

默认：

```text
one-or-more blank lines = paragraph separator
```

若一个 section 完全没有 blank-line separator，则 fallback：

```text
each non-empty physical line = one paragraph
```

这解决常见“每段一行”的 TXT/PDF extraction，而不引入 semantic paragraph guessing。

paragraph text：

- 保留原语言；
- trim paragraph 外围空白；
- 内部字符不翻译、不重写。

IDs：

```text
CH001_P0001
CH001_P0002
...
```

paragraph ID duplicate 是 blocking integrity failure。

## 9. A1 current / revision / reuse semantics

Pointer kind：

```text
CURRENT
```

Pointer ID：

```text
<project_id>.source.src_001
```

流程：

```text
read source
→ hash raw bytes
→ deterministic parse
→ build SourceDocument
→ validate
→ compare with exact current SourceDocument
```

如果 current SourceDocument canonical payload 与新结果完全相同：

```text
reuse current ArtifactRef
no new source revision
no pointer move
```

如果 raw content、parser/version、encoding choice、declared language 或 deterministic parse output 有 semantic change：

```text
new source_document revision
→ persist immutable artifact
→ persist ValidationReport
→ CAS CURRENT pointer
```

旧 revision 保留，不覆盖。

Crash 留下 orphan SourceDocument artifact 时不得因为“revision 最大”自动成为 current。Current authority 只来自 Foundation pointer head。

Budgets 属于 profile，不进入 Chunk schema hard-coded constant。

## 11. Deterministic token estimate

A2 当前先不绑定未来 A3 provider/tokenizer。

MVP planning counter：

```text
utf8-bytes-div3-v1
```

定义：

```text
estimate(text) = max(1, ceil(len(text.encode("utf-8")) / 3))
```

理由：

- deterministic；
- 无网络/model download；
- CJK 约 3 UTF-8 bytes/character，可作为保守 planning unit；
- 英文通常会比常见 BPE token 数略保守；
- 不假装这是 Qwen exact tokenizer。

Chunk artifact 必须记录：

```text
token_count_method
context_token_count
ownership_token_count
```

A3 provider adapter 后续仍必须在真正发送 request 前执行 provider-specific context preflight；A2 estimate 不得被解释为 provider exact token count。

## 12. A2 ownership algorithm

每个 chapter 独立规划；默认不跨 chapter 生成 Chunk。

### Ownership pass

从 chapter 第一个 paragraph 开始 greedy：

```text
加入连续 paragraph
直到再加入下一 paragraph 会超过 ownership_token_budget
→ 当前 ownership chunk 结束
→ 下一个 paragraph 开新 chunk
```

如果单个 paragraph 自身超过 `ownership_token_budget`：

```text
fail closed
```

A2 不拆 paragraph，因为 paragraph 是 canonical provenance 最小单位。

### Context expansion

对每个 ownership span：

- 向左加入最近 paragraph，最多 overlap budget；
- 向右加入最近 paragraph，最多 overlap budget；
- 不跨 chapter；
- profile validation 保证 ownership + 两侧最大 overlap 不超过 context budget。

Chunk IDs：

```text
CH001_C001
CH001_C002
...
```

稳定性要求：

```text
same SourceDocument exact ref
+
same exact profile content
+
same planner version
→ identical chunk payloads / manifest
```

```text
chunk_manifest
```

```json
{
  "schema_version": 1,

    "multiply_owned": 0
  },
  "state": "CHUNKING_COMPLETE"
}
```

`chunk_refs` pin exact immutable Chunk revisions；不得只写 chunk path 或 logical ID。

## 15. A2 coverage gate

在 manifest 成为 current 之前必须证明：

```text
owned_once == paragraphs_total
unowned == 0
multiply_owned == 0
chunk_count == len(chunk_refs)
```

并逐个证明：

- chunk ref exact resolve；
- chunk SourceDocument ref == manifest SourceDocument ref；
- chunk paragraph IDs 均存在；
- context span 与 paragraph_ids 首尾一致；
- ownership span 是 context span 的连续子区间；
- ownership 不跨 chapter；
- chunk ID / chapter ID / paragraph order deterministic；
- context/ownership token estimate 不超过 profile budget。

任何 failure：

```text
ChunkManifest 不得成为 current
A3 不得继续
```

## 16. A2 revision / reuse semantics

Manifest Artifact ID：

```text
<project_id>.src_001.<profile_id>
```

Current pointer ID：

```text
<project_id>.chunks.src_001.<profile_id>
```

同一 current SourceDocument ref + 完全相同 profile snapshot + planner_version：

```text
reuse current manifest
no new chunk artifacts
no pointer move
```

SourceDocument revision 或 profile/planner semantic content 改变：

```text
new SourceChunk revision set
+
new ChunkManifest revision
+
validation
+
CAS current manifest pointer
```

历史 chunk/manifest 保留。

Orphan chunk/manifest revision 不得通过 max revision / timestamp 自动成为 current。
