# B1.3 Alice one-window operator CLI

Run `scripts/b13_alice_live_acceptance.py` from a checkout with the project installed. Both roots are mandatory absolute paths with existing, canonical, operator-owned parents that are not group/world writable. Use trusted, stable parents and a filesystem with reliable locks and fsync. The roots must be disjoint from each other and the Foundation artifact and pointer trees. The final root directories may be created by live execution; parents are never created. Keep the same roots for every invocation.

Run the command without `--execute-live` to inspect fresh authority, runtime, tokenizer, checkpoints and claims without generation or writes. A successful inspection is not authorization and does not replace the fresh checks in a live invocation. The request model and strategy are pinned in the existing Alice preflight. The live flag permits at most one new window, with at most two semantic rounds and three technical attempts per round (six provider attempts total). The budget is printed before dispatch.

The final JSON line is bounded and omits source and response contents. Null provider attempts after a live failure means the dispatch outcome is unknown, not zero. Do not automatically retry a failed invocation: an unresolved or invalid claim blocks generation and needs separate operator investigation. A verified checkpoint can be reused on a later invocation. No publication or CURRENT update is performed.

Preflight HTTP requests use `--preflight-timeout` (default 120 seconds). Live execution requires an explicit `--generation-timeout`, applied per provider attempt; 1800 seconds is the suggested first-run value. Both timeouts must be in `(0, 3600]` seconds. Read-only mode uses the preflight timeout for runtime metadata if no generation timeout is supplied. The live budget report prints both values before dispatch; a timeout is runtime metadata and does not change semantic request identity.

For example, given the existing trusted `/home/song` parent and the indicated checkout and story paths, the proposed live command is:

```bash
cd /home/song/projects/novel-to-short-drama
.venv/bin/python scripts/b13_alice_live_acceptance.py \
  --story-root /home/song/projects/novel-to-short-drama/runs/a4e_real_novel/a3e-real-novel/story \
  --base-url http://127.0.0.1:8080/v1 \
  --input-ceiling-tokens 65536 \
  --execution-root /home/song/b13-alice-execution \
  --checkpoint-root /home/song/b13-alice-checkpoints \
  --preflight-timeout 120 \
  --generation-timeout 1800 \
  --execute-live
```
