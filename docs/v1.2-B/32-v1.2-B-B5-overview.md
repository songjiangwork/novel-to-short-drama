# v1.2-B / B5 — Release Variant / Localization 总览

状态：**FROZEN**

## 1. 目标与边界

B5 将一个 exact `APPROVED EpisodeShotPlan` 转换为面向具体 release target 的、backend-agnostic、asset-unresolved、可审批 release semantic artifact。

核心边界：

```text
EpisodeShotPlan
= canonical editorial / camera semantics

EpisodeReleaseVariant
= release-specific realization of those semantics
```

B5 可以 refinement presentation，但不能 reinterpret canonical Shot Plan。

正式下游链：

```text
APPROVED EpisodeShotPlan
↓
Release Variant / Localization
↓
APPROVED EpisodeReleaseVariant
↓
Asset Resolution
↓
Execution Compilation
↓
v1.1 ProductionShot
↓
H3 / ComfyUI / QC
```

## 2. B5 完整结构

```text
B5.1 Release Variant Contract + Variant Context
B5.2 Dialogue / Language Localization
B5.3 Release Framing + Aspect-Ratio Adaptation
B5.4 Subtitle / Audio / Release Timing Adaptation
B5.5 Release Variant Validation
B5.6 Episode Release Variant Assembly
B5.7 Release Variant Review + Approval Gate
```

完整链：

```text

```

## 3. Canonical semantic firewall

Release variation 可以改变：

- target language / locale realization
- subtitle realization
- aspect-ratio framing realization
- safe-area handling
- spoken-duration realization
- release timing refinement
- platform presentation constraints
- generation-segmentation realization constraints within B4 policy

但不得 silent 修改：

- PlannedShot identity / order / structure
- ProductionUnit ownership
- PRIMARY/SUPPORTING PCR mapping
- Shot purpose
- reveal / audience knowledge authority
- canonical viewpoint / orientation / angle / movement semantics
- canonical continuity / transition semantics
- editorial Shot boundaries
- B4 timing-anchor semantics
- B4 generation-segmentation policy

无法在 canonical semantic envelope 内实现的 variation 必须显式 conflict，并 route 到拥有 authority 的上游阶段。

## 4. 三类 release change

```text
SAFE_REFINEMENT
CONSTRAINED_REFINEMENT
CANONICAL_CHANGE
```

`SAFE_REFINEMENT` 不改变 canonical obligations；`CONSTRAINED_REFINEMENT` 必须验证 semantic preservation；`CANONICAL_CHANGE` 不属于 B5 authority。

典型 escalation：

```text
wording / localization
→ B5.2

framing / safe area
→ B5.3

subtitle / release timing / audio semantic realization
→ B5.4

Shot design / editorial structure
→ B4

production staging / blocking
→ B3
```

必要时可以继续 route 到更早 upstream。

## 5. Localization / Framing / Timing 分层

```text
B5.2
= what the same canonical meaning is spoken as
  in the target language

B5.3
= how the same canonical Shot semantics fit
  the target release frame

B5.4
= how localized speech, subtitle, audio continuity
  and release timing are realized inside B4 contracts
```

三个阶段不能相互越权。

特别保持：

```text
localized_spoken_text ≠ subtitle_text
estimated_spoken_duration ≠ measured_audio_duration
canonical Shot timing ≠ release-specific timing realization
```

## 6. Asset / Backend 边界

B5 不绑定：

- concrete character / location images
- concrete WAV / TTS voice asset
- LoRA / embedding
- Picture N / reference slot
- H3 prompt
- ComfyUI node/workflow
- seed / sampler
- backend clip limit
- ProductionShot concrete segmentation
- final encoder/container/bitrate

B5 输出的仍然是 semantic release authority；具体资产和 execution 后续解决。

## 7. Validation / Assembly / Approval

```text
B5.5 = read-only integrated validation
B5.6 = deterministic canonical assembly
B5.7 = B5 唯一 formal human approval gate
```

B5.5 生成：

```text
validated_release_variant_bundle_hash
```

B5.6 只能 exact materialize 已验证 bundle，并保存：

```text
source_validated_release_variant_bundle_hash
```

B5.7 批准 exact：

```text
EpisodeReleaseVariant id
+
revision
+
content_hash
```

## 8. Approval scope

B4 一个 episode 最多一个 current approved ShotPlan；B5 则允许一个 episode 同时存在多个 approved release variants。

正式 scope：

```text
episode_id
+
ReleaseVariantIdentity
```

所以：

```text
E01 / zh-CN / 9:16
E01 / zh-CN / 16:9
E01 / en-US / 9:16
E01 / en-US / 16:9
```

可以同时 APPROVED。

同一个 approval scope 最多一个 current APPROVED revision。

## 9. Python / Qwen / Human

```text
Python
= refs / pins / IDs / revisions / hashes /
  deterministic assembly / structural validation /
  lifecycle / provenance / approval invariants

Qwen
= localization / semantic equivalence /
  framing reasoning / subtitle and pacing reasoning /
  semantic diagnosis

Human
= B5.7 final Release Variant approval
```

Qwen 可以生成 candidate、解释 finding、比较 revision，但不能 self-repair validation artifact、不能 self-approve。

## 10. Semantic artifact 与 generated media 分离

```text
EpisodeReleaseVariant
→ APPROVED

Generated media candidate
→ ACCEPTED / REJECTED / RETRY
```

`EpisodeReleaseVariant APPROVED` 不等于 concrete assets、ProductionShot、H3/ComfyUI execution 或最终视频已通过。
