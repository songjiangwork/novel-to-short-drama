# v1.2-B1.1 — Adaptation Target（冻结）

## 职责

`AdaptationTarget` 定义外部 adaptation constraints：

> 我们准备把这部小说做成什么规格、什么叙事取向的作品？

它不决定具体保留/删除哪个 event，也不决定 episode boundary。

同一本 Story Bible 可以对应多个独立 AdaptationPlan / AdaptationTarget。

---

## Raw → Resolved

B1.1 先组合：

```text
raw user intent
+
profile defaults
+
explicit overrides
        ↓
ResolvedAdaptationTarget
```

后续 B1 stage 只消费 resolved target，不应在运行中到处重新推断 profile 默认值。

User override 优先于 profile default。重要值需要保留来源：

```text
user
profile_default
derived
model_proposed
```

`model_proposed` 不能被伪装成 user requirement。

---

## Duration / Episode Count

总时长、单集时长、集数必须支持语义：

```text
fixed
= 必须满足

target
= 尽量接近

range
= 在范围内优化

derived
= 根据其它条件推导
```

同时区分：

```text
hard constraint
soft preference
```

例如：

```text
episode target = 90s (soft)
episode max = 100s (hard)
```

可确定性发现的 target contradiction 必须在 semantic planning 前 fail closed。例如 fixed 20 集 × fixed 90 秒与 fixed 总长 1200 秒不能同时成立。

B1.5 最终解析 `resolved_episode_count`；B1.1 只定义 count constraint。

---

## Narrative Target

B1.1 可以表达：

- narrative format / medium
- presentation orientation（如 vertical short drama）
- adaptation genre target
- fidelity profile
- pacing profile
- compression profile
- primary character / plot focus
- audience target
- required elements
- forbidden elements
- working language

但不进入 codec、resolution、fps、H3 length、ComfyUI workflow、voice model、subtitle styling 等 delivery/runtime 配置。

---

## Fidelity

冻结 profiles：

```text
high
balanced
aggressive
```

它们是 adaptation decision policy，不是 event disposition 结果。

- `high`：尽量保持 major plot structure、character identity、relationship、causality、ending。
- `balanced`：允许 subplot omission、secondary-character compression、event merge、moderate reorder、bridge invention，同时保留核心 premise / main arc / resolution。
- `aggressive`：允许更强 character composite、subplot removal、timeline restructuring、major reorder；所有 divergence 仍需 provenance 与 review。

`aggressive != 随便改`。

---

## Pacing 与 Compression

两者独立：

```text
pacing
= adapted story 的 dramatic state 改变速度

compression
= source material 的保留/压缩程度
```

不能把 fast pacing 自动解释为 aggressive compression。

---

## Focus / Constraints

Primary focus 应尽量解析为 stable canonical/global IDs，例如 character、plot、relationship IDs。

自然语言 `required_elements` / `forbidden_elements` 应尽可能映射到 canonical entity/event/fact/relationship/plot IDs；无法可靠解析时保留 unresolved target constraint，禁止强猜。

---

## 语言边界

```text
working_language: zh-CN
```

表示 pipeline 中间材料默认工作语言。

最终 dialogue language、multilingual spoken dialogue、subtitle text 与 voice asset contract 属于后续 Release Variant / Localization，不由 B1.1 固定。

---

## 冻结原则

1. AdaptationTarget 独立于 Story Bible，不修改 source analysis。
2. Raw target 必须解析为显式 ResolvedAdaptationTarget。
3. hard / soft 与 fixed / target / range / derived 语义必须保留。
4. 可确定性 target contradiction 在 Qwen planning 前 fail closed。
5. Episode count 可 fixed、target、range 或 derived，不默认强制固定。
6. Fidelity 是 policy，不直接决定每个 event。
7. Pacing 与 compression 是不同维度。
8. User constraints 与 model-proposed values 必须可区分 provenance。
9. Required/forbidden elements 应 stable-ID-backed；无法解析允许 explicit unresolved。
10. B1.1 不承载 backend / H3 / ComfyUI / delivery configuration。
