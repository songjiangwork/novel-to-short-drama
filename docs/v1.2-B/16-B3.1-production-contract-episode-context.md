# B3.1 — Production Contract / Episode Production Context

状态：**FROZEN**

## 1. 职责

B3.1 从一个 `APPROVED EpisodeScreenplay` exact revision 构建 Production Planning 所需 authoritative context。

核心输出：

```text
EpisodeProductionContext
```

B3.1 不拆 ProductionUnit、不做 staging、不生成 Shot、不绑定 concrete asset。

## 2. Authoritative input / pinning

Production Planning 只能正式消费 `APPROVED EpisodeScreenplay`，并必须 pin：

```text
episode_screenplay_id
episode_screenplay_revision
episode_screenplay_hash
screenplay_approval_record_id
```

未批准 screenplay、聊天记忆、临时 Markdown/PDF、reviewer 尚未落入新 revision 的口头修改都不是 authoritative input。

Approval / revision / hash / stable reference 无法验证时 fail closed。

## 3. EpisodeProductionContext

`EpisodeProductionContext` 是 deterministic derived artifact，不是 production truth；应能从 approved screenplay + provenance 重建。

至少解析：

- ordered ScreenplayScenes / ScreenplayElements
- DramaticSettings
- participants / speakers / entrances / exits
- objective / conflict / turn / outcome context
- climax / hook context
- narratively meaningful actions
- object interactions
- important reactions / pauses
- DialogueIntent / subtext / emotional stance
- screenplay / narrative continuity relevant to production

## 4. Production Continuity

正式区分：

```text
Adapted Continuity
Screenplay Continuity
Production Continuity
```

`ProductionContinuityState` 是 execution-level overlay，可记录：

- visible appearance / injury
- wardrobe continuity
- prop visible condition / position
- important character presence/location
- door/window/environment state
- persistent performative/staging state

它不得创造或覆盖 narrative truth。

## 5. ProductionRequirement 概念

B3.1 正式引入 `ProductionRequirement`：为了忠实执行 screenplay，production 必须满足的 semantic requirement。

概念类别包括 character、location、prop、wardrobe、appearance、environment、action、performance、continuity 等；B3.3 再正式建模 requirement catalog。

核心边界：

```text
ProductionRequirement ≠ AssetBinding
```

例如“需要 Linsey / classroom / Document_X”合法；绑定 `linsey_face_100.png`、Picture 7、WAV 或 H3 reference 非法。

## 6. Must-be-realized semantics

重要 screenplay action / reveal / reaction 可以标记为必须在 production 中被感知实现，例如：

```text
Document_X signature reveal must be perceptibly realized
```

这只是 coverage obligation，不是 shot instruction。

## 7. Production invention boundary

B3 允许不改变 screenplay semantics 的 production realization invention，例如普通站位、走位、generic support detail。

若 production detail 改变 fact / causality / knowledge / relationship / possession / scene outcome / future dependency：

```text
SCREENPLAY_CHANGE_REQUIRED
```

若进一步要求改变 adaptation truth：

```text
ADAPTATION_CHANGE_REQUIRED
```

## 8. ProductionConstraintProfile

B3.1 可以消费抽象 `ProductionConstraintProfile`，例如 simultaneous performers、complexity、environment 等 production constraints。

约束必须与 screenplay truth 分离；constraint 不得 silent 删除角色、动作或改变剧情。

B3 architecture 不硬编码 H3 / ComfyUI / GPU capability。

## 9. Hierarchical context

长剧不加载全部历史 ProductionPlan。目标 episode context 可组合：

```text
approved screenplay
+
previous approved production ending checkpoint
+
selected long-range production continuity
+
ProductionConstraintProfile
```

Qwen 可声明需要某 stable-ID semantic context；Python 负责 deterministic authoritative retrieval。

## 10. Python / Qwen

Python：approval/pin 校验、ID/reference resolution、continuity gathering、constraint loading、context build、fail-closed validation。

Qwen：识别 production-semantic needs、meaningful actions、performance/visible continuity implications、targeted context need。

Qwen 不得猜 asset path 或 invent authoritative truth。

## 11. 冻结 contract

1. B3 只正式消费 APPROVED exact EpisodeScreenplay。
2. B3.1 输出 deterministic `EpisodeProductionContext`。
3. Context 不是 source of truth，可重建。
4. Exact screenplay id/revision/hash/approval pin 必须保留。
5. 无法验证 upstream 时 fail closed。
6. B3.1 解析 ordered screenplay structure 与 production-relevant semantics。
7. Adapted / Screenplay / Production Continuity 严格分层。
8. Production Continuity 是 visible/performative overlay，不得覆盖 narrative truth。
9. `ProductionRequirement ≠ AssetBinding`。
10. DramaticSetting 只转为 location semantic requirement，不绑定 background asset。
11. important action 可形成 must-be-perceptibly-realized obligation，但不是 Shot。
12. DialogueIntent / reaction / pause 可成为 performance semantic input。
13. Production realization invention 合法；narrative/screenplay invention 非法。
14. B3 不绑定角色图、voice、background、H3/ComfyUI/runtime。
15. B3.1 不生成 camera/lens/framing/Shot。
16. 可以消费抽象 ProductionConstraintProfile，但 constraint 不得 silent 修改 screenplay。
17. 使用 hierarchical context，不依赖全部历史 production plan。
18. Qwen identifies semantic need；Python resolves authoritative data。
