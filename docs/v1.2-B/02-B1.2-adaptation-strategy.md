# v1.2-B1.2 — Adaptation Strategy（冻结）

## 职责

`AdaptationStrategy` 回答：

> 针对这一部具体 source story，怎样达到 ResolvedAdaptationTarget？

它是全局 adaptation policy / priority 层，必须先于逐 event disposition。

输入：

```text
StoryBible
+
Global Canonical Skeleton / relevant canonical indexes
+
ResolvedAdaptationTarget
```

输出为全局 semantic planning，不直接替代 B1.3 的 concrete event decisions。

---

## 核心内容

AdaptationStrategy 至少要覆盖：

- adaptation thesis
- dramatic promise
- primary dramatic question
- main/subplot strategy
- character strategy
- relationship strategy
- reveal / payoff strategy
- series climax target
- ending strategy
- preservation priorities
- known deliberate divergences / conflicts

### Adaptation thesis

简短明确地说明本版本聚焦什么、牺牲什么、主要情感/剧情主线是什么，用于指导后续所有取舍。

### Dramatic promise

描述观众持续观看的核心承诺，与 adaptation thesis 分开。

### Primary dramatic question

定义贯穿 adaptation 的核心戏剧问题，并与 main plot / character arc / relationship arc 对齐。

---

## Plotline Strategy

A6 已识别 main plot / subplots；B1.2 对每条重要 plotline 给出战略 disposition：

```text
preserve
preserve_core
compress
merge_into
omit
```

`merge_into` 必须引用明确 target plotline。

B1.2 先决定 arc/plot 层面的取舍，B1.3 再执行到 canonical events，避免逐 event 时什么都舍不得删。

---

## Character Strategy

重要角色可使用：

```text
retain
reduce
omit
composite
retain_function
```

`retain_function` 表示角色本人可以被删除/合并，但其关键 narrative function 必须在 adapted story 中有明确承接者。

Composite character 是 adaptation decision，不得回写为 A4 entity merge。

---

## Relationship Strategy

重要 relationship arc 需独立规划：

```text
preserve
preserve_core
compress
simplify
omit
```

关系线不是 character 或 plot 的附属字段。`simplify` 允许保留核心关系变化、减少中间 state transitions。

---

## Preservation Priority

对关键 plot / character arc / relationship arc / reveal / turning point 可使用轻量 priority：

```text
critical
high
medium
low
```

这不是自动评分算法，而是 duration/compression 压力下的稳定 semantic planning output。

`critical` 不等于永远不能 omit；critical omission 属于高影响 decision，后续必须进入 review surface。

---

## Reveal / Ending Strategy

重要 reveal 可以规划：

```text
preserve
advance
delay
merge
omit
replace mechanism
```

advance/delay 属于 adapted presentation strategy，不修改 source chronology。

EndingStrategy 至少区分：

```text
source ending retained
source ending compressed
source ending reframed
adapted ending
```

`adapted ending` 或其它重大 source change 必须显式成为 deliberate divergence，并进入 B1.6/B1.7 review。

Series climax target 与 resolution target 应在全局 strategy 阶段明确，但不写具体 scene。

---

## Conflict / Divergence

如果 user constraints 与 source canon 或彼此冲突，禁止 silent reconciliation。

应显式产生：

```text
constraint conflict
requires_deliberate_divergence
```

是否接受 divergence 留给后续 review / approval。

---

## 长上下文策略

B1.2 不默认把全部 A5 raw evidence 塞进一次 Qwen 请求。

推荐：

```text
ResolvedAdaptationTarget
+
StoryBible
+
complete compressed global skeleton
+
important canonical IDs/indexes
+
conflicts/unresolved
+
targeted evidence expansion when needed
```

全局 strategy 必须基于覆盖整本故事的 compressed representation；不能由互相隔离的局部 1/4 规划后直接拼接。

---

## 冻结原则

1. AdaptationTarget = what we want；AdaptationStrategy = how this source story will achieve it。
2. Strategy 必须先于逐 event disposition。
3. Adaptation thesis / dramatic promise / primary dramatic question 是不同概念。
4. Plot、character、relationship 三类 strategy 都要独立表达。
5. Fidelity profile 是 policy，不是 concrete decision。
6. Preservation priority 用于稳定取舍，不是伪精确评分。
7. Reveal/ending 的重大改变必须 explicit divergence。
8. User/source conflict 不允许 silent resolution。
9. B1.2 不产生逐 event final disposition；具体执行属于 B1.3。
10. Global planning 必须看到完整 compressed story representation；必要时按 stable IDs 定向展开 evidence。
