# B4.3 — Shot Semantics / Composition / Camera Grammar

状态：**FROZEN**

## 1. 职责

B4.3 只为 B4.2 已存在的 `PlannedShot` 定义 per-shot cinematography semantics，不创建/删除/split/merge Shot，也不处理 cross-shot continuity。

正式输出：

```text
EpisodeShotSemanticsPlan
└── ShotSemanticSpecification[]
```

每个 PlannedShot exact 对应一个 `ShotSemanticSpecification`。

## 2. Coverage identity 与 camera realization 分离

```text
PlannedShot
= coverage identity / purpose / PCR responsibility

ShotSemanticSpecification
= cinematography realization
```

因此 camera refinement 不污染 B4.2 structural revision。

## 3. Orthogonal camera dimensions

不使用巨大 monolithic `shot_type`。v1.2 将 camera semantics 拆成正交维度。

### Shot scale

```text
EXTREME_WIDE
WIDE
FULL
MEDIUM
MEDIUM_CLOSE
CLOSE
EXTREME_CLOSE
```

这是 perceptual scale，不是物理焦距。`establishing / reaction / insert` 属于 shot purpose，不属于 scale。

### Viewpoint mode

```text
OBJECTIVE
OVER_SHOULDER
POV
```

OTS 必须记录 observer/target relation；POV 必须绑定 viewpoint character。

### Subject orientation

```text
FRONT
THREE_QUARTER
PROFILE
REAR
FLEXIBLE
```

### Camera angle

```text
EYE_LEVEL
HIGH
LOW
OVERHEAD
```

可用 qualifier 表达轻微/强烈变化；v1.2 不建立几十项 angle taxonomy。

## 4. Composition semantics

B4.3 使用 semantic composition，而非 pixel geometry。

可表达：

- primary attention
- secondary/contextual attention
- required visibility/readability
- must-co-visible relations
- foreground/background semantic relation
- light-weight occlusion tolerance
- ordered attention progression

不保存主体必须位于屏幕 x/y 百分比，也不绑定具体 background image geometry。

## 5. Attention progression

一个 continuous PlannedShot 可以有 semantic attention path，例如：

```text
Linsey → Document_X → Song reaction
```

但这里不建立 frame-accurate timeline；exact timing 属于 B4.5 / release refinement。

## 6. Camera movement intent

v1.2 核心：

```text
STATIC
REFRAME
FOLLOW
PUSH_IN
PULL_BACK
LATERAL_TRACK
ARC
OTHER_SEMANTIC
```

`STATIC` 也是显式 design choice。Movement 必须服务 perceptual / performance / spatial / editorial purpose，避免无意义 decorative movement。

Camera movement 不得改变 B3 staging；camera follows production truth，而不是 production truth 服务 camera。

## 7. Dialogue coverage

B4.3 不默认 camera 看 speaker。合法选择包括 speaker-oriented、listener-oriented、two-subject relation、OTS、POV 等。

Off-camera dialogue 是 visual coverage choice，不改变 canonical speaker/dialogue。

## 8. POV / OTS validity

POV 必须符合 viewpoint character 的 production position 与可见性，不能展示该角色不可能看到的内容，也不能通过 camera 提前制造 unauthorized knowledge。

OTS observer/target relation 必须与 staging spatial state 兼容。

## 9. PCR compatibility

Shot semantics 必须支持该 PlannedShot 的 PRIMARY PCR obligations。

例如 PRIMARY obligation 要求清晰识别小型文字，却指定 EXTREME_WIDE 且 object 仅 contextual，则 local semantics invalid。

SUPPORTING coverage 可以只保持 context-level readability，不要求成为 primary attention。

## 10. Reveal / knowledge protection

Camera visibility 不等于 reveal authority。B4.3 必须继续保护：

```text
world truth
character knowledge
audience knowledge
```

即使 secret 在 production space 中真实存在，也不能未经上游 presentation/PCR 授权提前给观众看。

## 11. Release / asset / backend 边界

Canonical composition 必须 frame-geometry agnostic，不绑定：

- 9:16 / 16:9 pixel layout
- subtitle-safe area
- concrete image/WAV
- Picture slots
- H3/ComfyUI prompt syntax
- physical lens/camera model
- precise camera x/y/z

Release Variant 可以在不改变 semantic intent 的前提下调整 concrete framing/crop。

## 12. B4.3 authority

在 coverage identity 不变时，以下通常只产生 B4.3 new revision：

- scale
- viewpoint
- angle
- composition emphasis
- movement intent
- attention progression

若需要 add/delete/split/merge/reorder Shot，或改变 PU/PCR ownership、fundamental purpose，则返回 B4.2。

## 13. Python / Qwen

Python：exact B4.2 pins、Shot/ref resolution、normalized taxonomy、provenance、revision/hash、boundary leakage checks。

Qwen：scale/viewpoint/angle/composition/movement/attention/reveal reasoning。

## 14. 冻结原则

1. B4.3 输出 versioned `EpisodeShotSemanticsPlan`。
2. 每个 PlannedShot 一个 exact ShotSemanticSpecification。
3. Camera dimensions 正交建模，不用 monolithic shot_type。
4. Composition 使用 semantic intent，不用 pixel coordinates。
5. Movement 保持 backend-agnostic 且必须有 semantic purpose。
6. B4.3 不拥有 Shot split/merge authority。
7. Dialogue coverage 不默认 speaker shot。
8. POV/OTS 必须 spatially/narratively valid。
9. Camera visibility 不拥有 reveal authority。
10. B4.3 不绑定 release/aspect ratio/asset/backend/runtime。
11. Cross-shot continuity 留 B4.4。
12. B4.3 不增加 formal approval gate。
